# Visual grounding brief — LoongReflect (2608.11967)

**Visual question:** How does LoongReflect make long-horizon search state reversible, and how are reflection/backtracking decisions trained?

**Grounded mechanism:** Show an active search trajectory accumulating evidence, an explicit `reflect` action that identifies verified evidence / missing evidence / branch risk, and a `backtrack` action that removes an unreliable suffix from active context and restores a trusted prefix while preserving a short corrective lesson. A compact training-side annotation may show local privileged reflection supervision plus terminal outcome learning feeding the recovery policy.

**Research delta:** The dominant contrast is append-only / contaminated active context versus **editable active state with rollback semantics**. The figure should teach state recovery, not generic “self-reflection.”

**Compared with:** Outcome-only or linear-context search agents where critique may be appended but failed trajectory state is not explicitly removed from the active context.

**Do not imply:** Do not imply that the retriever itself is new, that every reflection triggers backtracking, that privileged teacher information is available at inference time, or that the method proves transfer beyond the evaluated QA/math settings. Do not put benchmark numbers in the image.

**Grounding status:** Full paper checked on 2026-08-13.

**Preferred grammar:** State progression / trajectory learning. Use roughly 5–7 labels: `active path`, `reflect`, `risk/gap`, `backtrack`, `trusted prefix`, `lesson`, `outcome`. One named paper only; no repository/dashboard UI.

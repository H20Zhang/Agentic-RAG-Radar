# Visual grounding — EARM

**Visual question.** Can a memory retriever retain relevance judgments across queries instead of paying to reacquire every score?

**Grounded mechanism.** Each query directly scores selected anchors from the same candidate pool, appends them to a persistent query-memory matrix, completes missing scores with a warm-started low-rank model, and mixes observed/imputed scores for context selection.

**Research delta.** Make relevance judgments persistent retrieval meta-state and amortize future reranking calls.

**Compared with.** Semantic retrieval, full pointwise reranking, and observed-only anchors over the same fixed Mem0 store and 200-candidate pool.

**Do not imply.** The memory contents evolve; candidate recall expands; the schedule is uncertainty adaptive; savings include complete tokens/latency/dollars; or LoCoMo establishes generality.

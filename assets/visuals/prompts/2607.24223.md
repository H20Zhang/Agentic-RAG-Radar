# Visual grounding brief — RARG (2607.24223)

**Visual question:** How can relevance guide direct corpus interaction after a workspace has already been bounded?

**Grounded mechanism:** Relevance scores define document traversal order, initialize likely entry points, and prioritize local grep matches before limited observations reach the model. The agent still performs direct interaction and verification.

**Research delta:** Relevance becomes an execution prior rather than only a top-k content filter or workspace constructor.

**Compared with:** Raw DCI, RISE/RISE-BM25, and embedding retrieval agents.

**Do not imply:** Do not claim reranking is free—ordered grep/reranking add latency; do not imply embeddings are uniformly robust under corpus scaling; preserve the negative generative-reranking result.

**Grounding status:** Full paper and official code repository checked 2026-08-14.

**Preferred grammar:** Coarse-to-fine execution flow. Labels: `relevance`, `scope`, `traverse`, `grep`, `rerank`, `evidence`.

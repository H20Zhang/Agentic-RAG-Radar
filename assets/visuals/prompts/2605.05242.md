# Visual grounding brief — Direct Corpus Interaction (2605.05242)

**Visual question:** What evidence operations become possible when an agent moves from a fixed top-k retrieval API to direct corpus interaction?

**Grounded mechanism:** Contrast a retriever-mediated path (`query → top-k snippets`) with a raw-corpus environment where the agent composes `grep/find → local read → refine/verify`. Emphasize span/file-level interaction and feedback from observations to the next command.

**Research delta:** Retrieval-interface resolution: the agent controls fine-grained corpus operations rather than only issuing another similarity query.

**Compared with:** Sparse/dense top-k retrieval agents using ranked snippets/documents.

**Do not imply:** Do not claim lexical search universally beats dense retrieval; do not hide the documented full-corpus scaling failure; do not attribute gains solely to iteration because harness/context management also matters.

**Grounding status:** Full paper checked 2026-08-14; official DCI-Agent-Lite repository verified.

**Preferred grammar:** Before/after retrieval-interface diagram. Use 5–7 labels such as `top-k`, `corpus`, `grep`, `read`, `evidence`, `refine`, `answer`.

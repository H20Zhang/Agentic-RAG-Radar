# Visual brief — S2G-RAG

**Visual question.** How does S2G-RAG turn evidence sufficiency and explicit missing-information gaps into the next retrieval action?

**Grounded mechanism.** Show a compact evidence memory entering S2G-Judge. The judge branches to `sufficient → answer` or `insufficient → gap items → next query → retrieve → sentence evidence → update memory → judge again`. The gap items, not a free-form reasoning trace, are the key persistent control representation.

**Research delta.** Make the structured sufficiency/gap state visually dominant. The important distinction is explicit progress state plus a deterministic query-construction path from missing information.

**Compared with.** Iterative RAG where the next search is triggered/formulated from raw provisional answers or reasoning history without an explicit structured gap representation.

**Do not imply.** Do not imply that S2G-RAG learns retrieval depth k, changes the search engine, or proves explicit state is universally better outside benchmark QA. Keep the sentence-level Evidence Extractor visible only as compact-memory support, not as the main novelty.

**Grounding status.** Full-text checked from ACL 2026 paper, including matched-budget ablations.

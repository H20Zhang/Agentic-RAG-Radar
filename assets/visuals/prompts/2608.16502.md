# Visual grounding — ToolScout

**Visual question.** How can a fixed tool registry still lose gold-capability coverage when a dense retriever is adapted to one source-defined slice?

**Grounded mechanism.** A query-side TF-IDF compatibility signal estimates whether the incoming source style is safe for a specialist checkpoint. Safe traffic stays on the specialist; unsafe traffic switches to an aggregate-trained checkpoint; matched supervision can later repair the specialist. Candidate coverage is measured before reranking and execution.

**Research delta.** Treat source compatibility as a deployment-time routing guard for executable-capability retrieval.

**Compared with.** The fixed ToolRet-1100 specialist, the aggregate-trained retriever, BM25/fusion controls, skill-card rerendering, and matched few-shot continuation.

**Do not imply.** Query wording alone causes the collapse; routed coverage proves end-task agent success; the method generalizes to document RAG; or routing is cheaper than keeping a broad checkpoint without lifecycle accounting.

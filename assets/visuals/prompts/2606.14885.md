# Visual grounding brief — DR-DCI (2606.14885)

**Visual question:** How does an agent dynamically expand a persistent workspace with retrieval and then use DCI inside it?

**Grounded mechanism:** Hidden/full corpus on the left; agent issues `pull(query,k)` to add ranked documents to persistent workspace state; local `grep/read/compare` operations happen only inside the workspace; new constraints can trigger another pull.

**Research delta:** Retrieval becomes a state-changing workspace-management action rather than a one-shot context selector.

**Compared with:** Raw full-corpus DCI and a single/static retrieved workspace.

**Do not imply:** Keep workspace-preserving context reset visually separate/optional; do not attribute all gains to pull alone because harness/materialization/ranked preview matter; do not use external uncontrolled baselines as causal proof.

**Grounding status:** Full paper and official code repository checked 2026-08-14.

**Preferred grammar:** Stateful control loop. Labels: `corpus`, `pull`, `workspace`, `grep`, `read`, `verify`, `answer`.

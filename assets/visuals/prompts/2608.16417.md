# Visual grounding — D2-ScaleAgent

**Visual question.** After reading the current Evidence Bank, how does the controller distinguish “find another page” from “read an already found page more deeply”?

**Grounded mechanism.** The Verifier reads page-, region-, and atomic-evidence state plus completeness/gap fields. A breadth gap triggers weighted parallel page retrieval, rank fusion, and pruning. A depth gap routes to Surveyor, Locator, or Extractor. New evidence returns to the bank; the loop ends only after declared evidence closure or a budget limit.

**Research delta.** Make breadth-versus-depth allocation an explicit evidence-sufficiency decision instead of treating every unresolved question as generic “search more.”

**Compared with.** Fixed multimodal RAG and iterative seeker/inspector pipelines without a resource-matched control that exposes the same multi-granularity state.

**Do not imply.** The Verifier alone caused the reported gain; the method is cheaper; all direct VQA baselines are weaker; or closure guarantees correctness.

# Visual brief — SGR-Bench

## Visual question

What does state-gated retrieval add to search-agent evaluation beyond simply finding the right website or page?

## Grounded mechanism

Show a task entering a search agent that first discovers the correct specialized website, then must configure a site-specific retrieval state through filters, views, hierarchies, scopes, time windows, or result pages before answer-bearing evidence becomes visible. The visual should contrast **right source / wrong state** with **right source / correct state / evidence exposed**.

## Research delta

The benchmark makes retrieval state itself an evaluation object. Its paired constraint-guided and goal-oriented tasks hold source and answer fixed while varying how much retrieval logic is explicit, and its failure audit shows that many systems reach the relevant source yet drift into the wrong retrieval scope or criteria.

## Compared with

Open-web search benchmarks focused on source discovery/traversal and browser-agent benchmarks focused on generic action execution rather than expert data-retrieval sites with state-gated evidence.

## Do not imply

- Do not imply source discovery is solved; it is necessary but often not sufficient.
- Do not equate site-specific retrieval state with the agent's internal memory/evidence state; one is environment configuration, the other is controller state.
- Do not present the system rankings as model-only rankings because CLI/harness choices are part of the evaluated systems.
- Do not generalize the reported failure percentages beyond the audited benchmark trajectories.

# Visual grounding — CTIFoundry

**Visual question.** What changes when the same stock agent accesses a frozen CTI corpus as flat files versus through a validated scaffold and typed operations?

**Grounded mechanism.** Offline construction materializes official relation edges, canonical entities, provenance-linked chunks, and hybrid retrieval. Online, seven typed tools expose resolve/get/traverse/search/collect/read operations; task-specific user-turn skills guide entity linking, attribution, and multi-document synthesis.

**Research delta.** Make corpus structure and evidence paths directly operable by an unchanged agent harness.

**Compared with.** The same stock mini-swe-agent over the same corpus exposed through one generic bash surface, plus tools-only and skills-only ablations.

**Do not imply.** Flat files cannot reach evidence; graph structure alone caused the gain; the system learns a new policy; the result generalizes beyond frozen CTI; or tool-call reductions are complete lifecycle savings.

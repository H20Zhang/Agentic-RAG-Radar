# Visual grounding — StateMem

**Visual question.** How can an agent assemble current state without replaying superseded facts as if they were still active?

**Grounded mechanism.** State units record supersession and dependencies; deterministic checks withhold inactive facts and flag derived state for recomputation before answer-time rendering. A separate one-call wrapper traces question-relevant value chains over backend retrieval plus the full transcript.

**Research delta.** Separate historical recall from validity-aware state assembly and test structure against a matched generic full-context summarization control.

**Compared with.** Recall-oriented memory/retrieval backends and the same one-call, full-transcript wrapper format without value chains, turn numbers, operative-state fields, or precedence rules.

**Do not imply.** Dependency propagation is uniformly beneficial; persistent StateMem is cheaper than long context; wrapper gains over backend-alone isolate structure; StateMemBench generalizes unchanged; or the method is a new search controller.

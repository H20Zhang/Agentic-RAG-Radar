# Agentic RAG Monthly — 2026-08

> **Coverage:** 2026-08-01 to 2026-08-12 · **Status:** rolling · **Finalization:** after August closes

## Month thesis

**August is not the origin of agent-native retrieval; it is where a control stack that already existed in pieces becomes easier to factor and evaluate.**

The strongest current map is:

`information environment → explicit state → adaptive policy/stopping → resource allocation → operating-point evaluation`

The Aug-12 backfill makes three chronology corrections. **S2G-RAG** already made sufficiency/missing-information state explicit in April. **SPARKLE** already trained a plug-and-play retrieval policy against adaptive/search-RL baselines. **When Should Active RAG Retrieve?** already showed that nominal retrieval budgets need held-out calibration, harm audits, and controller-cost accounting.

So the durable August signal is **factorization + stricter causal attribution**, not “the field suddenly discovered adaptive retrieval.”

## Emerging field map

### 1. Environment and interface are separate from policy

A-RAG exposes keyword/semantic/read operations. LLM-Wiki compiles documents into a linked workspace and ablates progressive traversal. READ exposes lexical search, structural navigation, and bounded reads. DocNavRAG makes document hierarchy/cross-links navigable.

The important tension is empirical. LLM-Wiki reports a large drop when traversal is removed while structure remains; READ reports BM25 statistically indistinguishable from its agentic method. Sometimes runtime policy matters substantially; sometimes the primitive dominates. A credible paper needs both sides of that ablation.

### 2. Explicit state predates DocNavRAG—and changes what DocNavRAG should claim

S2G-RAG maintains a compact Evidence Context and uses a judge to predict `sufficient` or structured missing-information gaps. Removing the judge causes a large quality drop under fixed retriever, turn cap, per-turn top-k, and answer reasoner.

That makes **explicit evidence/gap state** an earlier, better-controlled design point. DocNavRAG remains interesting because it couples state to a document-native retrieval environment, but the novelty should be framed as **environment–state co-design**, not “first explicit missing evidence.”

### 3. Learned retrieval needs adaptive baselines and realized resource budgets

SPARKLE learns retrieval decision, query formulation, and knowledge integration in a separate proxy policy using RL while the answer LLM/retriever remain the environment. Its comparison against Search-R1/R1-Searcher-style policies raises the baseline bar for learning papers.

SAGE adds a different control variable: per-query k under a P95 latency SLO. Its systems point is useful, but static-k remains the main experimental baseline family. After SPARKLE, “strong adaptive comparisons are unavailable” is no longer a good excuse.

Know Before You Fetch separates calls, passage volume, and latency. The Active-RAG evaluation paper adds another layer: even a nominal 50% evidence-use target is not a matched budget if thresholds realize different held-out usage. Trigger computation also matters.

## Updated causal lens

The radar now uses:

`substrate × operation set × state × policy × realized resources × base model × historical baseline`

“Realized resources” includes what actually happened on held-out queries—not only the configured target—and separates evidence-use rate from controller/probe/generation cost.

The historical axis asks where novelty lives once classical retrieve→verify→reformulate loops are acknowledged: state representation, learned policy, interface, scale, transfer, or a genuinely new action space.

## Most important design points

**S2G-RAG — ★★★★☆.** Strong explicit-state predecessor with a matched-budget no-judge ablation.

**SPARKLE — ★★★★☆.** Strong learned-policy baseline; plug-and-play separation is cleaner evidence than a generic “RL beats static RAG” story.

**LLM-Wiki / READ — ★★★★☆.** Together show why interface and policy must be separated: one supports strong traversal value, the other contains a lexical baseline reversal.

**Know Before You Fetch / Active-RAG evaluation — ★★★★☆.** Together turn “budget” into a multi-axis, calibrated operating point rather than one scalar.

**Forgotten History or Test-of-Time? — ★★★★☆.** Raises the novelty baseline beyond LLM-era papers while stopping short of claiming technical equivalence.

## Core tension

The same headline “adaptive RAG wins” can arise because the system changed the **environment**, exposed better **state**, learned a better **policy**, or simply used a better **resource operating point**. Those are different contributions and should be independently visible in the experiment.

A second tension is now harder to ignore: an apparently sophisticated learned controller can be less informative than a simple uncertainty/lexical baseline if the experiment does not match the operating point.

## Evidence audit

The strongest evidence currently comes from component-matched ablations or negative results: S2G-RAG's no-judge ablation, LLM-Wiki's structure-versus-traversal ablation, READ's BM25 result, and Active-RAG's matched-usage/harm analysis.

The recurring weakness is not lack of benchmarks; it is **bundled causality**. Base model, interface, state, policy, and resource use still change together too often.

## Open problems

1. **State abstraction:** does explicit evidence/gap state beat raw history across substrates, not only multi-hop QA?
2. **Adaptive-vs-adaptive control:** compare prompted, supervised, and RL policies using identical tools and answer models.
3. **Operating-point evaluation:** extend matched realized resources from binary retrieve/skip to variable turns, k, context size, and multi-tool agents.
4. **Harness sensitivity:** tool-result delivery and agent harness may be another causal axis; this deserves systematic incorporation into future backfill/evaluation.
5. **Beyond document QA:** web research, SQL/data analysis, code, scientific search, and multimodal evidence remain underrepresented.

## Rolling status

The month-to-date map remains three clusters, but their meanings are sharper:

1. **environment + explicit state**;
2. **adaptive policy + resource allocation**;
3. **causal, budget, and novelty evaluation**.

New papers should change one of these clusters or its evidence standard; otherwise they belong in the archive, not the homepage thesis.

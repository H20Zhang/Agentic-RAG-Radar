# Agentic RAG Monthly — 2026-08

> **Coverage:** 2026-08-01 to 2026-08-26 · **Status:** rolling · **Finalization:** after August closes

## Month thesis

**August is a placement-of-work and evidence-path story.** The field is not well described by `static RAG → agentic multi-round search`. Five variables must be separated:

`evidence/capability coverage × materialization time × operation surface × retained state × lifecycle resources`.

SIRA and ReFind separate pre-retrieval compilation from result-conditioned access. LENS moves evidence localization to query time. D2-ScaleAgent routes page breadth versus reading depth. VisDocAgentBench and CTIFoundry reinforce explicit evidence-path operations across visual documents and typed knowledge scaffolds. ToolScout shows that failure can occur before planning when candidate capabilities do not transfer across source distributions. StateMem and EvoWiki now jointly separate historical retention from operative-state resolution at answer time versus write time. The latest evidence further separates fresh-context allocation from feedback scheduling, typed constraint retention from generic compaction, prior retrieval experience from reacquisition, and post-hoc failure labels from live intervention.

## New placement signals — exposure, ownership, compaction, and acquisition

Six additions sharpen placement without creating five new trends. Risk-Aware Reranking moves safety policy to the shortlist before execution, but evaluates exposure rather than executed outcomes. NIS-Agent's fixed-results Observer Mode supports a narrower interface claim—separating search ownership from validation changes judgment—while its full trajectory gain remains bundled. Compaction Cliff suggests hard constraints need typed protection under tight state budgets, but the type metadata is unmatched. EARM treats prior judged retrieval episodes as reusable ranking state, with evidence limited to one fixed memory store and query order. SkillAlchemy places adaptivity at skill admission, yet lacks a matched acquisition budget.

EvoWiki is the exception at the synthesis level. Its matched no-overwrite control reinforces StateMem: retrieving history and resolving current-valid state are distinct operations. The new comparison is lifecycle placement—StateMem assembles validity at answer time, while EvoWiki materializes supersession during writes. This changes the State persistence map, but not the broader map axes.

## 1. Evidence-path operations become a map-level interface axis

VisDocAgentBench tests static and iterative policies under the same top-10 opaque page delivery. CTIFoundry compares flat bash access with a scaffold exposing `resolve / traverse / collect / read` to the same stock agent. Their domains and treatments differ, but both make the route from query to inspectable evidence more explicit.

This reinforces, rather than replaces, earlier DCI/RISE/RARG/SIEVE work. The map tension is now:

`opaque top-k ↔ explicit search / resolve / traverse / inspect / read under a shared output contract`.

The boundary is causal: VisDoc changes backend and accumulated history in major comparisons; CTIFoundry bundles graph/entity materialization, typed tools, descriptions, prompt placement, and skills.

## 2. Adaptivity has more than one placement

SIRA compiles a discriminative action before reading passages. ReFind adapts from names, times, and local context revealed by prior results. D2 adds a narrower online decision: whether current evidence calls for another page or deeper inspection of a found page.

D2's verifier ablation is useful, but one paper does not establish a broad routing direction. A decisive comparison would fix page candidates, reader, model, and total tokens/calls/latency while varying only breadth/depth allocation.

## 3. Retrieval can fail before the controller acts

ToolScout adds capability coverage to the causal lens. A planner cannot select a tool absent from its candidate set, and a retriever that works in one source style may collapse on a mixed source. Routed aggregation restores much of the measured coverage, but end-task execution is missing.

The useful order is:

`evidence/capability exists → candidate retrieval → interface delivery → agent inspection/planning → execution`.

## 4. State and removed work still have a price

RAAC exposes progress/stagnation state; LoongReflect makes active reasoning state reversible; SGR-Bench exposes external retrieval state. The context-compression study shows that dropping queryable state can create repeated retrieval while completion stays flat. LENS shows that avoiding a persistent index shifts work into online localization.

Therefore “fewer search calls,” “no index,” and “smaller context” are incomplete without controller, localization, reacquisition, update, token, tool, and latency accounting.

## 5. State validity becomes an evaluation variable

StateMem adds a different evaluation intervention: retrieve history, then ask which facts remain operative. Its matched wrapper control attributes 15.0–31.7 points on StateMemBench to value-chain structure beyond the same transcript, chunks, call, and intermediate length. The external boundary is sharp: dependency propagation can hurt, and DeepSeek/LongMemEval gains over generic full-context summarization are only −5 to +5 points.

This is a new signal, not a durable trend. It extends the causal path into **validity-aware state assembly** without establishing that the full memory package generalizes.

## 6. New controllers need stronger matched controls, not broader labels

ASCP provides the cleanest new result: fresh rotation at fixed context and rounds is much better than reusing the same evidence, while full feedback scheduling is statistically tied with deep rotation and their matched resource delta is unreported. A separate equal-slot comparison shows sequential `(2,12)` taking 17.5s versus 1.7s for one-shot `(24,1)`, so it is a compute/interface-package result rather than a timing-only effect. SSE-Bio similarly supports a narrower statement than its system label: a four-way source selector beats fixed schedules inside one harness, but routing accounts for only a minority of audited failures. GTA-RAG's chain reward improves same-package chain coverage, yet graph construction, hybrid retrieval, synthetic targets, and training remain bundled.

CAS and MCite-RL add two smaller learning signals. Variable evidence-set sizing beats fixed top-k in an internal ablation, but conformal set coverage is not answer correctness. Bbox reward improves citation IoU, but its process term uses only the terminal crop and bbox overlap does not establish semantic support.

## 7. Context and evaluation become executable environments

Scroll keeps history lossless in an event log and persistent Python namespace, then materializes selected state at query time. Its REPL ablation is stronger than its cross-system leaderboard; complete storage, execution, latency, and dollar accounting remains open. AgenticRAG-FP takes the same environment-first principle into evaluation: certified hop faults plus frozen/suffix reruns retain diagnostic information that final answer coverage loses after propagation. The evidence is narrow and survivor-conditioned, so this is a causal-evaluation coordinate rather than a depth law.

## Causal synthesis

The current lens is:

`substrate/evidence coverage × capability coverage × pre-retrieval observability × materialization × backend × operation surface × source/environment state × harness/delivery × retained agent state × policy × realized resources × base model × training protocol`.

A packaged trajectory gain should not be attributed to retrieval or planning until the first unmatched factor is located.

## Evidence audit

Strongest evidence comes from matched or factorized contrasts: ReFind's generic-agentic and one-search controls; RAAC's same-agent overlays; LENS's stale-index/sequential ablations; the compression paper's oracle restoration; D2's verifier/removal cells; VisDoc's search/inspection ablations; CTIFoundry's base/tools/skills/full grid; ToolScout's matched/mixed/routed source tests.

Main gaps are equally concrete: unmatched online work, changed retrieval backends, accumulated-history differences, bundled operation surfaces and prompts, missing update lifecycles, and proxy-only rather than executed outcomes.

## Open problems

1. Match backend, output contract, accumulated history, and total budget when testing evidence-path operations.
2. Separate new-page coverage from deep inspection and charge verifier cost.
3. Measure capability recall before planning and executed success after routing.
4. Account for offline construction/update plus online tokens, tools, context, and latency.
5. Counterfactually repair one evidence-path failure and test whether the trajectory recovers.

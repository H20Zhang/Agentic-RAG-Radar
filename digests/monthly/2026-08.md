# Agentic RAG Monthly — 2026-08

> **Coverage:** 2026-08-01 to 2026-08-13 · **Status:** rolling · **Finalization:** after August closes

## Month thesis

**August is not the origin of agent-native retrieval; it is where an existing control stack becomes easier to factor, stress-test, and now repair.**

The strongest current map is:

`information environment → explicit/editable state → adaptive policy/stopping → resource allocation → executable operating-point evaluation`

Earlier backfill corrected the chronology: S2G-RAG already made sufficiency/missing-information state explicit; SPARKLE already trained a retrieval policy against adaptive/search-RL baselines; Active-RAG evaluation already made realized usage/controller cost first-class. W33 now adds two sharper boundaries: **state rollback** through LoongReflect and **cross-source executable grounding** through VAKRA.

So the durable August signal is **factorization + stricter causal attribution + trajectory integrity**, not “the field suddenly discovered adaptive retrieval.”

## Emerging field map

### 1. Environment and interface are separate from policy

A-RAG exposes keyword/semantic/read operations. LLM-Wiki compiles documents into a linked workspace and ablates progressive traversal. READ exposes lexical search, structural navigation, and bounded reads. DocNavRAG makes document hierarchy/cross-links navigable.

The important tension remains empirical. LLM-Wiki reports a large drop when traversal is removed while structure remains; READ reports BM25 statistically indistinguishable from its agentic method. Sometimes runtime policy matters substantially; sometimes the primitive dominates. A credible paper needs both sides of that ablation.

### 2. State is moving from “what is missing?” to “what should remain active?”

S2G-RAG maintains an Evidence Context and predicts sufficiency or structured missing-information gaps. DocNavRAG couples evidence state to document-native navigation.

LoongReflect adds a materially different state operation: **backtrack** can remove a contaminated suffix from active context, restore a trusted prefix, and preserve a corrective lesson. This makes state an editable execution object rather than only a summary used to choose the next query.

The causal caveat is supervision. LoongReflect's fast channel has privileged global trajectory information during training. The next experiment should separate trajectory-tree representation, rollback action space, and privileged recovery labels.

### 3. Learned retrieval needs adaptive baselines and realized resource budgets

SPARKLE learns retrieval decision, query formulation, and knowledge integration in a separate proxy policy using RL while the answer LLM/retriever remain the environment. SAGE adds a different control variable: per-query k under a P95 latency SLO.

Know Before You Fetch separates calls, passage volume, and latency. Active-RAG evaluation shows that even a nominal evidence-use target is not a matched budget until held-out usage and trigger-side cost are measured.

LoongReflect reinforces the baseline lesson from another direction: adaptive/RL comparisons such as Search-R1 and AgenticRAG-R1 are practical, so static-only comparisons are increasingly weak evidence for learned control.

### 4. Evaluation must test cross-source trajectory integrity

VAKRA combines executable APIs with document retrieval and natural-language tool-use policies under a fixed ReAct harness. Its trace analysis finds that the difficult boundary is often **entity disambiguation and cross-source grounding**, not function-call syntax.

This matters beyond one benchmark. Agentic RAG systems increasingly claim to work over mixed sources—web, documents, databases, tools—but most evaluations still score those capabilities separately. VAKRA makes composition itself visible.

The missing piece is causal replay: a benchmark can tell us where a trajectory failed, but not yet whether patching source selection, entity grounding, retrieval, or memory state would repair it.

## Updated causal lens

The radar uses:

`substrate × operation set × state × policy × realized resources × base model × historical baseline`

W33 adds two refinement questions:

- **State semantics:** is state descriptive, append-only, or explicitly editable/recoverable?
- **Environment composition:** are abilities tested independently, or must identity/evidence remain coherent across heterogeneous sources in one executable trajectory?

These are not new top-level taxonomy axes yet; they are stress tests for claims on the existing stack.

## Most important design points

**LoongReflect — ★★★★☆.** Makes rollback/recovery a first-class state-control action and trains it with local privileged supervision plus global outcome optimization.

**VAKRA — ★★★★☆.** Adds executable API+document composition and exposes cross-source grounding as a concrete failure boundary.

**S2G-RAG / SPARKLE — ★★★★☆.** Remain the key earlier baselines for explicit gap state and strong adaptive-policy comparison.

**LLM-Wiki / READ — ★★★★☆.** Together show why interface and policy must be separated: one supports strong traversal value, the other contains a lexical baseline reversal.

**Know Before You Fetch / Active-RAG evaluation — ★★★★☆.** Turn “budget” into a calibrated multi-resource operating point rather than one scalar.

## Core tension

The same headline “adaptive RAG wins” can arise because the system changed the **environment**, exposed better **state**, added rollback semantics, learned a better **policy**, or simply used a different resource operating point. Those are different contributions and should be independently visible in the experiment.

A second tension is now clearer: a controller optimized on document QA may fail for reasons that are not “search policy” at all once the environment mixes APIs and documents. **Entity/schema grounding can dominate trajectory quality.**

## Evidence audit

The strongest current evidence comes from component-matched ablations or diagnostic negatives: S2G-RAG's no-judge ablation, LLM-Wiki's structure-versus-traversal ablation, READ's BM25 result, Active-RAG's matched-usage/harm analysis, LoongReflect's recovery/training ablations, and VAKRA's executable trace analysis.

The recurring weakness is still **bundled causality**. LoongReflect changes state representation, action space, and supervision together. VAKRA bundles several failure sources in one cross-source trajectory even while keeping the harness fixed.

## Open problems

1. **State recovery:** does rollback beat append-only reflection when representation and supervision are matched?
2. **Cross-source grounding:** how should agents maintain entity/provenance identity across documents, APIs, SQL, and web sources?
3. **Adaptive-vs-adaptive control:** compare prompted, supervised, and RL policies using identical tools and answer models.
4. **Operating-point evaluation:** extend matched realized resources from binary retrieve/skip to variable turns, k, context size, recovery actions, and multi-tool agents.
5. **Intervention benchmarks:** patch one intermediate decision and re-execute to attribute final failure causally rather than only label the trace.

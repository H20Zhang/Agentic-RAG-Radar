# Agentic RAG Yearly — 2026

> **Coverage:** 2026-01-01 to 2026-08-17 · **Status:** rolling · **Scope note:** this is a year-to-date map over papers currently curated by the radar, not a claim of complete historical coverage.

## Year-to-date thesis

**The durable 2026 shift is from “retriever + agent” toward explicit design of where information-acquisition intelligence lives.** The important objects are now: what is precomputed, what the controller can observe before retrieval, what operations the interface preserves, what new information arrives only after evidence inspection, what state persists or can be repaired, and what resources are actually spent.

The newest correction is **adaptivity placement**. SIRA shows that some multi-round exploration can be compiled into a corpus-aware retrieval action before evidence is read. ReFind shows the opposite regime: on distributed chat history, result-conditioned iteration plus session/time/local-context controls materially outperform both one-search and generic multi-round BM25 controls.

The methodological bar also moves earlier. Retrieval, Reward, and Training Protocols shows that a training corpus can omit answer-bearing evidence while the model still receives positive final-answer reward from parametric knowledge. A retrieval-learning claim is therefore invalid before policy comparison if the external evidence channel cannot support the task.

## 1. Retrieval becomes an adaptivity-placement and interface problem

A-RAG exposes explicit retrieval operations. DCI makes **retrieval-interface resolution** first-class; RISE and DR-DCI restore scalable boundaries; RARG carries relevance into local execution; SIEVE separates candidate admissibility, ranking, inspection, and reading.

SIRA and ReFind add a more fundamental split:

`compile before retrieval ↔ adapt after observing evidence`.

SIRA uses model priors plus document-frequency/index signals to predict and validate discriminative vocabulary before final retrieval. ReFind leaves raw chat untouched and lets later queries exploit newly surfaced names, timestamps, and session-local context.

Neither establishes a universal winner. SIRA pays offline corpus-enrichment cost in its main setup and has a backbone/budget reversal on BrowseComp-Wikipedia. ReFind has a task where single-shot BM25 slightly wins and pays several LLM/search calls per query. The durable research question is **what information is available at each stage and where total system cost should be spent**.

Pi-Serini prevents another false dichotomy: a conventional lexical backend can appear weak because it is poorly tuned, too shallow, or badly exposed to the agent. “BM25,” “dense,” “one-shot,” and “agentic” are all too coarse as experimental labels.

## 2. State has multiple layers and owners

S2G-RAG makes sufficiency/missing-information state explicit. DocNavRAG couples evidence state to document-native navigation. LoongReflect adds rollback/recovery over active reasoning state. DR-DCI highlights persistent external workspace state.

SGR-Bench adds **environment retrieval state**: the correct source can still expose the wrong evidence because filters, views, hierarchies, scopes, or time windows are wrong.

The durable distinction is:

`external source state ≠ persistent evidence workspace ≠ internal evidence/reasoning state`.

A generic “memory” label obscures which layer failed and which intervention could repair it.

## 3. Learning moves from policy optimization to environment validity

Agentic-R changes retriever utility toward trajectory-level downstream value. Critic-R turns reasoning dissatisfaction into query repair and retriever supervision. GrepSeek learns direct-corpus actions. SearchMaster makes the self-generated task distribution a controlled object. LoongReflect learns recovery.

Retrieval, Reward, and Training Protocols adds the harder prerequisite: **the retrieval environment must make the task externally answerable.** When answer-bearing passages are missing, final-answer reward can reinforce parametric recall rather than retrieval behavior. The same study also shows that process-level rewards can trade off supporting-document recall, redundancy, and search depth instead of uniformly improving accuracy, and that larger search budgets can make trained agents worse.

Thus “better search-agent RL” is not one variable. A credible claim must identify both the learned object and the environment/protocol that made the supervision valid.

## 4. Evaluation becomes an end-to-end causal path

The current lens is:

`substrate/evidence coverage × corpus boundary/interface resolution × environment retrieval state × harness/delivery × agent state × policy × realized resources × base model × training distribution/protocol × historical baseline`.

The ordering is the important part:

`evidence exists? → backend exposes it? → agent can inspect it? → external state is correct? → controller chooses well? → harness preserves evidence? → trajectory keeps identity/evidence coherent?`

Training Protocols, Pi-Serini, SGR-Bench, Is Grep All You Need?, and VAKRA each isolate a different failure in that path. Forgotten History or Test-of-Time? adds a different constraint: the control-loop shape may be old even when the model/interface/scaling regime is new.

## 5. Resource accounting becomes offline + online

Know Before You Fetch separates retrieval calls, context volume, and latency. SAGE makes per-query `k` an explicit action. When Should Active RAG Retrieve? audits held-out usage and trigger-side costs.

The new adaptivity-placement tension adds a systems dimension: **offline preprocessing and query-time adaptation are substitutable resources**. SIRA spends LLM compute on corpus-side enrichment in its main setup; ReFind avoids semantic preprocessing but spends multiple searches and LLM calls at question time. Pi-Serini adds surfaced-versus-inspected ranking depth; SIEVE adds selective read granularity.

A smaller prompt is not necessarily cheaper retrieval. Fewer rounds are not necessarily less total compute. No preprocessing is not no cost.

## What has weakened

**“Agentic = more retrieval rounds.”** SIRA shows that corpus-aware pre-retrieval compilation can eliminate some exploratory interaction; ReFind shows the opposite boundary where evidence-conditioned iteration matters. Round count is an outcome of information availability, not a capability metric.

**“Better retriever = better information access.”** DCI, Pi-Serini, SIEVE, and ReFind collectively separate backend recall, interface resolution, candidate admissibility, inspection, and substrate-native controls.

**“Found the right source = retrieval succeeded.”** SGR-Bench shows the source can still be in the wrong retrieval state.

**“Finer RL reward = better search policy.”** Training Protocols shows corpus coverage, tool format, off-policy degree, and budget can dominate or reverse the conclusion; process reward can also distort search behavior.

**“Same model + different retriever = controlled.”** Backend tuning/depth, interface, harness, state, evidence coverage, and total resource point still need to match.

## Open problems entering the rest of 2026

1. **Adaptive placement:** predict when to compile retrieval before evidence versus spend result-conditioned interaction after evidence under matched total compute.
2. **Semantic-symbolic co-design:** expose enough corpus statistics/structure to compile strong actions without reintroducing a lossy hard top-k bottleneck.
3. **Layered state semantics:** separate and jointly control source state, persistent workspace/evidence, compacted memory, and reversible reasoning state.
4. **Training-environment validity:** verify answer-bearing evidence coverage before optimizing RL rewards or self-generated curricula.
5. **Factorial executable evaluation:** swap backend, interface, state, harness, controller, and model independently with realized-cost logging and counterfactual repair.
6. **Cross-source generalization:** test these abstractions on APIs, SQL, graphs, code, multimodal archives, and live web search.

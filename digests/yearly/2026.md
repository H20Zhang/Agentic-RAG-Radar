# Agentic RAG Yearly — 2026

> **Coverage:** 2026-01-01 to 2026-08-12 · **Status:** rolling · **Scope note:** this is a year-to-date map over papers currently curated by the radar, not a claim of complete historical coverage before backfill matures.

## Year-to-date thesis

**The durable 2026 shift is the factorization of information acquisition into separately researchable objects: environment/interface, explicit evidence state, adaptive policy/stopping, and resource allocation.**

The second durable lesson is methodological. A serious comparison increasingly needs both **causal matching** and **operating-point matching**: hold the information interface and answer model as fixed as possible, compare against strong adaptive policies, and report what resource budget was actually realized—not only what was configured.

A third lesson is historical: many closed-loop control shapes predate LLMs, so novelty should be located in modern state representation, policy learning, interface, scale, or transfer.

## Durable shifts so far

### 1. Retrieval becomes an agent-facing environment

A-RAG exposes explicit keyword/semantic/read operations. LLM-Wiki compiles documents into linked, inspectable pages. READ and DocNavRAG sharpen the interface argument for structured documents.

The evidence is deliberately mixed. LLM-Wiki reports a substantial drop when progressive traversal is removed while keeping its compiled environment; READ reports BM25 statistically indistinguishable from READ in its setting. The stable conclusion is **interface × policy**, not that either one universally dominates.

### 2. Evidence progress becomes explicit state

S2G-RAG is now the clearest early-2026 baseline: a sufficiency/gap judge turns missing information into the next retrieval query, and a matched-budget ablation shows a large drop when that controller is removed. Search-o1 provides the reasoning-time retrieval anchor; DocNavRAG later couples explicit evidence state to document-native navigation; ACE-GraphRAG uses context gaps to select graph-context policy.

This changes the chronology and the novelty claim. **Explicit missing-information state is not an August invention.** The interesting question is which state abstraction transfers across environments and whether it beats raw history under equal resource use.

### 3. Policy learning gets a stronger baseline

SPARKLE learns retrieval decision, query formulation, and knowledge integration in a separate proxy policy while treating the answer LLM/retriever as the environment. Graph-R1 learns multi-turn graph interaction; Agentic-R moves retriever learning toward trajectory utility; SAGE learns per-query k from an SLO-aware oracle.

The important shift is not merely `heuristic → learned`. It is that **adaptive-vs-adaptive comparison is now feasible**. SPARKLE's matched-generator results are competitive rather than uniformly dominant, which makes it a more useful benchmark for causal policy claims than static-only comparisons.

### 4. Resource budget becomes both an action and an operating point

Know Before You Fetch separates retrieval calls, passage volume, and latency. SAGE makes k a per-query learned action. When Should Active RAG Retrieve? adds a crucial evaluation distinction: a nominal target evidence-use rate is not a matched budget until thresholds realize comparable held-out usage.

Its cost decomposition also exposes controller-side work. An uncertainty router can pay for a no-retrieval generation before deciding; a retrieval-score router can pay for a probe retrieval. Thus `same evidence usage` is still not automatically `same cost`.

### 5. The novelty baseline gets older

Forgotten History or Test-of-Time? reconstructs classical IR/QA precedents for retrieve→verify→reformulate loops. This does not make modern Agentic RAG unimportant; it changes where the novelty burden sits.

The durable question is now: **what new capability is enabled by modern models and environments, compared with a strong implementation of the older control principle?**

## The evaluation standard 2026 is forcing

The current lens is:

`substrate × operation set × state × policy × realized resources × base model × historical baseline`

A credible causal claim should control the first six as much as possible. `Realized resources` means held-out calls, retrieved/context tokens, controller/probe compute, and latency—not merely a target percentage or maximum turn cap.

A credible novelty claim should explain the historical axis rather than dismiss it. A similar loop can be old while a learned state/action representation or scalable environment remains genuinely new.

## What has weakened

**“Agentic = iterative retrieval”** is no longer a useful contribution statement. S2G-RAG, Search-o1, modern 2026 systems, and classical IR/QA all make the space more specific than that.

**“Adaptive beats static”** is no longer a sufficient learning baseline. SPARKLE shows contemporary adaptive/search-RL comparisons are practical.

**“Same target budget = fair comparison”** is also too weak. Calibration transfer, retrieval harm, and controller-side costs can reverse the interpretation.

## Open problems entering the rest of 2026

1. **Minimal sufficient information API:** expressive enough for complex evidence needs but small enough for reliable control.
2. **Transferable explicit state:** evidence coverage, provenance, uncertainty, and missing requirements across documents, web, SQL, code, graphs, and multimodal data.
3. **Adaptive-vs-adaptive policy evaluation:** prompted, supervised, and RL controllers on identical interfaces and answer models.
4. **Multi-resource operating points:** extend calibrated budget frontiers from retrieve/skip to variable turns, k, context size, tool choice, and wall-clock constraints.
5. **Harness/tool-delivery confounds:** determine when the agent runtime itself changes the apparent retriever or policy ranking.
6. **Historical baseline discipline:** reimplement strong older control ideas when they attack the same information-acquisition decision.

## Week thesis

**W35 strengthens one durable state claim while making the attribution bar for “adaptive search” harder: evidence acquisition, materialization, current-valid state, and reuse are separable control surfaces, and richer trajectories do not earn policy credit unless a simpler allocation/interface control is matched.**

This closed digest uses only records accepted by the Radar inside the complete local week. Publication date is chronology; `radar_published_at` determines weekly membership.

## 1. Current-valid state is not the same object as retrieved history

StateMem and EvoWiki independently target supersession rather than raw recall. StateMem resolves operative facts at answer time; its matched wrapper versus generic full-context summarization attributes **15.0–31.7 points** on StateMemBench to chronology/precedence structure across six backends. EvoWiki moves the same lifecycle decision to write time; keeping extraction, coreference, entity structure, and reader fixed while removing overwrite drops macro accuracy from **60.09 to 51.46**.

Together they reinforce the existing `supersession-aware-state-assembly` direction: preserving history and deciding which state is currently valid are different operations, and the latter can be placed at read time or write time. The ceiling remains medium because StateMem's strongest margins are on a synthetic benchmark built around stale-state failures, while EvoWiki reads about **17K tokens/query** and does not directly score provenance quality.

## 2. “Evidence reached” splits into materialized, answerable, and grounded state

AWM supplies the cleanest post-retrieval control this week. With gold evidence pages fixed, AWM-GRPO still raises final/memory-only accuracy from **45.4/41.2 to 48.0/43.5** and lowers memory-missing-correct from **19.1% to 16.4%**. EviGraph goes one step earlier in the loop by committing verifier-approved source spans into claim-level support/conflict state; the clean same-architecture result is **26.9% to 35.9%** on BrowseComp-Plus after RL.

The common research implication is narrower than “memory helps”: page access, state writing, claim grounding, and downstream use need separate measurements. AWM's answerability judge is not claim-level provenance; EviGraph's frozen verifier supplies privileged semantic judgments. MCite-RL adds the same warning in visual RAG: bounding-box overlap can improve without establishing that the cited region semantically supports the answer.

## 3. Adaptivity must beat strong allocation and bounded-search controls

ASCP separates fresh evidence from feedback scheduling: at `k=2,T=12`, fresh rotation reaches **0.397** PR versus **0.257** for fixed reuse, yet full ASCP is statistically tied with deep rotation (**0.309 vs 0.303, q=0.343**). The sequential equal-volume setting also costs roughly **17.5s versus 1.7s** for one-shot allocation, so the result is an allocation/compute frontier, not a timing-only policy win.

Crase provides the complementary structural challenge: fixed 1.5-hop citation exploration reports **R@50 0.3659** with **5 calls / 235K tokens / 104s / $0.37** on ICLR versus **0.1220** and much larger reported budgets for two open-ended deep-research baselines. That comparison changes output contract, models, corpus access, and substrate, so boundedness is a required baseline, not an isolated causal winner. NIS-Agent and SSE-Bio sharpen the placement question further: identical returned observations can change re-search decisions under different context ownership, and a matched state-conditioned source router can beat fixed source schedules before downstream reasoning.

## Core tension / alternative explanation

The apparent shift toward richer agent state has a simpler competing explanation: several systems also expose more information, retain more tokens, invoke extra verifiers/readers, or move work offline. Scroll retains a lossless queryable event log but lacks matched lifecycle cost; Compaction Cliff protects typed constraints using metadata unavailable to score-only controls; EARM reduces direct reranker calls by **74.43%** on one fixed memory/query stream but omits complete token/latency accounting. These are useful mechanisms, not yet proof that persistent state dominates reacquisition under a common resource budget.

Learning results have the same confound. CAFE's matched **500-online-step** study shows that alternation schedule itself materially changes performance; GTA-RAG bundles graph construction, hybrid retrieval, synthetic trajectories, and reward; CAS changes evidence-set width and trajectory weighting; SkillAlchemy changes acquisition queries, source mix, admission schema, and compiled skill content. Credit should stay at the smallest matched intervention.

## Evidence audit

**Strongest controls:** StateMemWrapper versus generic full-context summarization; EvoWiki versus no-overwrite; AWM EP-given gold-page control; EviGraph RL versus no-RL in the same dual-role architecture; ASCP fixed reuse versus fresh rotation; SSE-Bio learned routing versus fixed source schedules.

**Largest unresolved confounders:** privileged verifier/metadata access, unmatched evidence exposure and retained tokens, extra training-time reader/feedback calls, different output contracts or retrieval substrates, incomplete construction/update cost, and schedule-dependent online optimization.

Risk-aware tool reranking is also a useful negative boundary: adding a risk head reduces UltraTool RVR@5 from **0.188 to 0.138** while NDCG@5 changes **0.558 to 0.551**, but no tool is executed, so candidate exposure is not downstream safety. Failure-propagation probes similarly improve causal diagnosis only by rerunning trajectories, making diagnostic power and extra compute inseparable unless both are reported.

## Reading order

**ASCP → AWM → StateMem → EvoWiki → EviGraph → Crase**: first learn how to separate evidence freshness from controller complexity, then isolate post-retrieval materialization, then move current-state resolution across the read/write boundary, and finally compare explicit evidence state with structurally bounded exploration.

## Questions carried forward

1. Under one corpus, output contract, model, and total resource budget, does feedback-conditioned allocation beat strong fresh rotation or structurally bounded search?
2. If evidence pages are fixed, which intervention matters most: extraction/write policy, source-grounded state representation, or the consumer that reconstructs and uses that state?
3. What is the lifecycle break-even point between retaining structured retrieval state and reacquiring evidence, once ingestion, update, verification, storage, tokens, tool calls, and latency are all priced together?

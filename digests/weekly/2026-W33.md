# Agentic RAG Weekly — 2026-W33

> **Coverage:** 2026-08-10 to 2026-08-16 · **Status:** finalized · **Timing basis:** original paper publication date; legacy Radar acceptance timestamps are unavailable

## Week thesis

**W33 contains four distinct early signals, not one controller trend:** raw-chat runtime access (ReFind), progress-aware stopping/redirect (RAAC), reversible search state (LoongReflect), and executable cross-source evaluation (VAKRA).

The common lesson is narrower: information access must expose enough state for a controller or evaluator to locate failure. The four papers do not establish that one shared architecture or “more iteration” is better.

## Four in-period signals

### ReFind — runtime interface over raw chat

ReFind reports 93.2/89.3 on its LongMemEval interface ablation versus 78.7/82.2 for generic multi-round BM25 and 84.7/68.9 for one-search. The controls support session/time/local-context operations and result-conditioned access. EventQA slightly favors one-shot BM25, so runtime iteration is not universally necessary.

### RAAC — observable progress control

RAAC exposes coverage, novelty, query diversity, and drift, then chooses continue/intervene/stop. On BrowseComp-Plus it reduces searches by about 14 while improving average accuracy by about three points. Controller and re-thinker LLM calls are not charged in that search-count comparison, and several cells regress.

### LoongReflect — reversible active state

LoongReflect lets the agent backtrack to a trusted prefix while retaining a corrective lesson. Qwen2.5-3B averages 46.15 F1 across seven benchmarks versus 33.55 for AgenticRAG-R1. The teacher sees privileged global trajectory information, so the result supports the recovery-learning package more strongly than rollback alone.

### VAKRA — executable cross-source trajectories

VAKRA combines APIs, document retrieval, policy constraints, and multi-hop composition under a fixed ReAct harness. The best model reaches 70.4% on single-hop tasks but only about 50–51% compositional API accuracy, with some policy-constrained unanswerable settings at 2.4%. This diagnoses entity grounding and cross-source composition; it does not identify a controller that repairs them.

## Causal synthesis

The four papers expose different intervention points:

`source interface → progress state → active trajectory state → executable evaluation`

Their costs and controls are not interchangeable. ReFind isolates interface affordances; RAAC adds controller work; LoongReflect adds privileged recovery supervision; VAKRA fixes a harness for diagnosis. A packaged trajectory gain cannot be attributed to retrieval or planning without matching interface, evidence delivery, and total budget.

## Reading order

**ReFind → RAAC → LoongReflect → VAKRA**: move from source access, to progress control, to recovery state, then test whether the resulting abstractions survive cross-source execution.

## Questions carried forward

1. Which observations justify result-conditioned interaction rather than pre-retrieval compilation?
2. Do progress-aware stopping gains survive full controller token/latency accounting?
3. Can rollback be separated from privileged recovery supervision?
4. Can executable benchmarks repair one intermediate failure and measure causal trajectory recovery?

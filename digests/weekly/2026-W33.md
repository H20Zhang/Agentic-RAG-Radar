# Agentic RAG Weekly — 2026-W33

> **Coverage:** 2026-08-10 to 2026-08-16 · **Status:** rolling · **Adjacent context:** SIRA (May) is used only to interpret ReFind's August result.

## Week thesis

**W33 shifts the question from “how agentic should retrieval be?” to “where should retrieval intelligence live?”**

ReFind shows that pre-built semantic memory structure can sometimes be replaced by **question-time control over a faithful raw archive**. LoongReflect makes the resulting active execution state **reversible** when a long search branch becomes contaminated. VAKRA then stress-tests whether identity and evidence remain coherent when the trajectory crosses APIs and documents.

The falsifiable thesis is therefore: **runtime interaction is valuable only when it exposes information that could not have been compiled before retrieval; once that interaction becomes long or heterogeneous, state recovery and trajectory integrity become first-class bottlenecks.**

## Three durable shifts

### 1. Memory design becomes a placement-of-computation problem

ReFind does not argue that semantic memory is useless. It asks whether the system should pay to summarize/embed/structure every update **before the future question is known**, or instead preserve raw chat and spend adaptive compute only when a query arrives.

Its matched controls matter more than the headline leaderboard. Generic multi-round BM25 is materially weaker than ReFind, so iteration alone does not explain the result. Forcing one search is also materially weaker on LongMemEval-M, so some later queries really benefit from information revealed by earlier evidence. The EventQA reversal—single-shot BM25 is slightly better—prevents a universal “iterate more” conclusion.

**Adjacent counterpoint: SIRA.** SIRA shows the opposite regime: when an LLM can predict discriminative evidence vocabulary and validate it using corpus-visible statistics before retrieval, some exploratory rounds can be compiled away. The research variable is therefore not round count but **what information becomes observable before versus after retrieval**.

### 2. Internal state becomes editable, not merely descriptive

S2G-RAG and DocNavRAG already made sufficiency/missing-evidence state explicit. LoongReflect changes the control surface: a reversible trajectory tree supports `reflect` and `backtrack`, restoring a trusted prefix while preserving a corrective lesson.

The evidence is stronger than a static-baseline story but still bundled. LoongReflect compares against adaptive/RL search systems and reports large gains across seven RAG benchmarks; its teacher, however, sees privileged global trajectory information unavailable to the deployed student. The result supports the **recovery-learning package** more strongly than rollback alone.

### 3. Evaluation moves from component skill to trajectory integrity

VAKRA combines executable APIs, document retrieval, multi-hop composition, and policy constraints under a fixed ReAct harness. Its useful result is diagnostic: compositional tasks fail around **entity disambiguation and cross-source grounding**, not only API syntax.

That is a different failure mode from LoongReflect's contaminated search branch. A rollback action cannot be assumed to repair entity/schema grounding; cross-source verification or representation alignment may be the missing mechanism.

## Most important papers

**ReFind — ★★★★☆.** Strong because it includes both a matched generic-agentic control and a one-search control. The reusable idea is raw-data fidelity plus substrate-native runtime access, not “BM25 beats memory.”

**LoongReflect — ★★★★☆.** Reversible active state plus recovery-specific supervision is a meaningful control abstraction; privileged teacher information remains the main attribution caveat.

**VAKRA — ★★★★☆.** Executable API+document composition exposes a failure surface that document-only QA hides. It is an evaluation contribution, not a new controller.

## Core tension

W33 should not be summarized as “more online agent control wins.” SIRA and ReFind point in opposite directions for good reason.

- **Compile before retrieval** when the discriminative information is already observable from corpus/index structure.
- **Defer to result-conditioned interaction** when new names, times, relations, or local context become available only after inspecting evidence.

The decisive systems question is **which side can access the necessary information at lower total cost without destroying evidence fidelity**. Offline index/memory construction and query-time search calls are substitutable resources, not free architectural choices.

## Evidence audit

ReFind's strongest causal evidence is internal: generic-agentic BM25 versus the full chat-native interface, plus one-search versus multi-round control. Its strongest GPT-5-mini ablations are on small fixed LongMemEval subsets, so broad generalization remains open.

LoongReflect has good adaptive/RL comparisons and component ablations, but privileged global teacher information weakens component-level attribution.

VAKRA fixes the harness and executes tool calls, improving comparability, yet its aggregate errors still bundle source selection, entity grounding, policy interpretation, and synthesis. Counterfactual replay remains the missing evaluation primitive.

## Minimal reading order

**SIRA → ReFind** to understand the new pre-retrieval-compilation versus result-conditioned-interaction tension.  
**S2G-RAG → LoongReflect** to see explicit evidence state become recoverable execution state.  
**VAKRA** last to ask whether those abstractions survive heterogeneous source boundaries.

## Questions to carry forward

1. Under matched total compute, when does **pre-retrieval compilation** beat **result-conditioned iteration**, and what observable corpus signals predict the crossover?
2. Can rollback be separated from privileged recovery supervision under the same state representation and action space?
3. Can executable benchmarks patch one failure—query/action, source state, entity grounding, or evidence delivery—and measure whether the trajectory causally recovers?

# Beyond Semantic Similarity: Rethinking Retrieval for Agentic Search via Direct Corpus Interaction

**arXiv:** [2605.05242](https://arxiv.org/abs/2605.05242) · **Published:** 2026-05-03 · **Category:** Retrieval & Tool Use · **Importance:** 5/5 · **AI confidence:** High

> **TL;DR.** DCI makes the corpus itself the agent's retrieval environment: instead of asking a fixed similarity API for top-k evidence, the agent composes grep/find/read/shell operations over raw files. The enduring contribution is **retrieval-interface resolution**, not a claim that lexical search universally beats learned retrieval.

## Problem

A top-k interface decides which documents/snippets are visible before the agent can apply exact conjunctions, inspect local context, or recover evidence filtered out by ranking. Stronger reasoning cannot recover information the interface never exposes.

## Core idea

Remove the separate retrieval API and let the agent search raw corpus files directly with general-purpose terminal operations. The agent can combine exact patterns, structural navigation, local reads, counts, and follow-up commands as its information need changes.

## Agent loop

`hypothesis → grep/find/shell → inspect local evidence → extract new constraint/entity → refine command → verify → answer`

## Compared to what

The closest comparison is retriever-mediated agentic search with the same answer model but sparse/dense top-k results. The paper also ablates restricted DCI tool sets and runtime context-management choices.

## Evidence

With Claude Sonnet 4.6 on BrowseComp-Plus, the paper reports **80.0%** accuracy for DCI versus **69.0%** for a Qwen3-Embedding-8B retrieval agent, while estimated total API cost falls from **$1,440 to $1,016**. More important than the headline score, trajectory analysis finds many DCI wins even when the retrieval agent had already surfaced gold documents: local evidence localization and verification appear to matter.

The counterweight is scale. Full-corpus shell interaction degrades sharply as distractors grow; broad commands become slow/noisy and tool budgets are exhausted. Later work should therefore be read as attempts to preserve DCI resolution without full-corpus scans.

## Why it matters

DCI changes the research unit from **retriever quality** to **agent-facing corpus interface**. That is a durable abstraction because a capable agent may need operations that are not expressible as another natural-language similarity query.

## Limitations / questions

- Raw DCI has a real scalability envelope; high interface resolution is not free.
- Exact lexical interaction is brittle to paraphrases, aliases, and surface-form variation.
- Harness/context-management changes can materially alter DCI performance, so interface and harness must be factorized experimentally.

**Curator take:** **5/5.** A defining 2026 design point because it creates the interface-resolution lens that later bounded-workspace systems refine. The important claim is not “grep replaces vectors”; it is that retrieval APIs constrain what an agent can observe and do.

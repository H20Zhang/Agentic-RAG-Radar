# From Inertia to Objectivity: Improving Deep Research Agents with Noise Isolation

*发表于 2026-08-24 · 迭代推理与验证 · 重要性 4/5 · 已阅读全文 · 置信度：中*

[论文](https://arxiv.org/abs/2608.23045)

> **TL;DR。** NIS-Agent 把新搜索观察与 agent 自己写出的 trajectory 隔离，再在停止前验证带引用的 inference steps。IBIS 中，在相同 task/results 下换成 observer context，多数模型的 re-search 判断提高约 15–30 点。GAIA/WebWalkerQA 与 token 结果有潜力，但完整 package 同时改变 filter、validation 与部分 harness。

| **为什么重要** | 相同 evidence 会因 surrounding context 的“作者身份”不同而触发不同检索决策。 |

## Problem

agent 是否因为自己早先的 search narration 而产生惯性，误判页面充分性、re-search、验证与停止？

## 研究增量

增量是 **ownership-isolated search validation**：worker 在不看自有 trajectory 的条件下判断当前 observation；manager 再把 trace 重组为引用明确的局部推论并分别检查。

## Mechanism

**控制流。** `search → 隔离 task/query/results → browse 或 re-search → 重建 cited steps → 局部验证 → 修正或停止`

这既是 harness intervention 也是 policy intervention：它改变每个决策能看见的 state，以及 evidence 如何交给 validator。

## Closest comparison

最近的因果对照是 Observer Mode：固定任务与 search results，只改变搜索职责隔离和验证视角；完整 agent package 不是 matched component control。

## Decisive evidence

| 主张 | 证据 | 最近控制 | 判断 |
|---|---|---|---|
| ownership 改变 re-search | Observer 约 +15–30 点 | 相同 task/observations | 强局部因果证据 |
| package 改善 GAIA | GPT-4o **54.88 → 61.82** | 同 backbone/smolagents 基线 | package-level |
| 两组件都有贡献 | 56.96 → 58.79 → 61.82；去 filter 59.39 | nested ablation | 较好但非完整 factorial |
| token 更少 | **219.8K → 147.3K** | 同端到端基线 | 整体成立 |

8B 结果混合了 SFT、GRPO、teacher actions/rubrics 与 interface。Filter 可能丢掉描述弱但相关的页面；隔离验证也可能批准错误步骤。

## Field-map consequence

`observation → ownership framing → inspect/re-search → cited validation → stop`

它把 context ownership 加入 evaluation/harness decomposition，仍是单篇信号。

## What remains unproven

重放完全相同的 search trace，对 trajectory visibility、observation rendering、filter、validator stage 与 stopping 做 factorial，并匹配 calls/tokens/latency，同时测 evidence recall 与 unsupported confident answers。

# Structurally-bounded Agentic Graph Exploration for Evidence-Grounded Scholarly DeepSearch

*Published 25 Aug 2026 · Retrieval & Tool Use · Importance 5/5 · Full-text reviewed · Confidence medium*

[Paper](https://arxiv.org/abs/2608.24809) · [Code](https://github.com/RadiantCrystal/CRASE)

> **TL;DR.** Crase is a useful counterexample to “deep search must stay open-ended.” It searches externally only for seeds, then fixes a 1.5-hop citation neighborhood, prunes edges by claim-level support, and ranks within that bounded graph. On ICLR it reports **R@50 0.3659 vs 0.1220** for both proprietary deep-research baselines while using **5 vs 17–18 calls, 235K vs 560–620K tokens, 104 vs 249–272 s, and $0.37 vs $1.76–$2.06**. But the output task, corpus substrate, and models also differ, so boundedness itself is not isolated.

## Research question

When a domain already contains useful relational structure, can we replace open-ended model-controlled exploration with a bounded search space whose stopping rule is known before inference?

## Research delta

Crase changes the control surface:

`open-ended search/read/stop loop → seed queries → fixed 1.5-hop citation graph → claim-support pruning → deterministic graph ranking → top-k`

The key idea is not merely graph retrieval; it is **structural bounding of future information acquisition** after seed selection.

## Mechanism

An LLM decomposes the query and issues a fixed number of Semantic Scholar seed searches. Crase expands seeds through references and citing papers, extracts 4–5 atomic claims per paper, scores citation edges with a fine-tuned scientific entailment model, prunes unsupported edges, then runs recency-aware PPR or SALSA. Once seeds are fixed, candidate space and stopping are fixed; model judgments are local rather than controlling whether the global loop continues.

The clean lesson is *not* that “less agentic is always better.” It is that open-ended adaptivity should compete against a structurally bounded alternative under the same output contract and cost accounting.

## Where it fits

`query plan → bounded corpus interaction → explicit evidence graph → predetermined stop`

This is an `early_signal` for moving stopping and exploration bounds out of the policy when domain structure permits. It does not yet revise the general Field Map.

## Open question

Use the same scholarly corpus, seed retriever, generator, output contract, and dollar/token budget; compare fixed 1.5-hop expansion, adaptive hop expansion, and open-ended tool search. That would reveal when adaptivity actually pays for itself versus merely increasing variance and cost.

# AWM: Answerable Working Memory for Long-Document VQA Agents

*发表于 2026-08-26 · 学习与优化 · 重要性 4/5 · 已阅读全文 · 置信度：中*

[论文](https://arxiv.org/abs/2608.25618) · [代码](https://github.com/DongzhuoranZhou/AWM)

> **TL;DR。** AWM 把“找到 evidence”和“把 evidence 保存在 terminal working memory 中”拆成两个能力。同一 Qwen3-VL-4B family 下，Answer-GRPO → AWM-GRPO 在 MMLongBench-Doc 为 **51.6→53.9**，LongDocURL 为 **57.4→60.1**；gold evidence pages 的 EP-given control 下，final/memory-only accuracy **45.4/41.2→48.0/43.5**，`Pmmc` **19.1%→16.4%**。最稳的结论是 evidence materialization，而不是 retrieval backend 优势。

| 30 秒判断 | |
|---|---|
| **为什么重要** | page recall 与 final answer 之间还有一个可独立失败的 state-writing 层；否则检索成功后的证据丢失会被误诊成 search failure。 |
| **最强证据** | EP-given 固定 gold evidence pages 后，final/memory-only/Pmmc 仍从 **45.4/41.2/19.1% → 48.0/43.5/16.4%**。 |
| **最大限制** | 训练每个 rollout 多两次 frozen Qwen3-14B text pass；memory-only answerability 也不是 claim-level source grounding。 |

## Problem

retrieval agent 已经到达相关页面之后，写入的 working state 是否仍可能因为没有保住 question-relevant evidence 而成为独立 bottleneck？

## Mechanism

Qwen3-VL-4B policy 通过固定 Jina-v4/Qdrant 接口每次取 top-3 page images，检查后必须追加 source-linked finding，再决定是否继续。GRPO 训练时，frozen Qwen3-14B reader 只从 `(question, terminal memory)` 作答，另一个 frozen scorer 同时评价 memory-only answer 与 final answer；reward 优先正确且 memory 可作答的 trajectory。部署时不增加 reader/scorer call。

## Closest comparison

最关键控制不是 AWM package 对 static RAG，而是同一 agent family 的 Answer-GRPO：policy、RAG Top-3 harness、tools、memory schema、prompts、optimizer 和 SFT checkpoint 保持一致，主要改变 reward。EP-given 进一步把 retrieval 替换成 gold evidence pages，从而隔离 page access。

## Decisive evidence

| 主张 | 证据 | 最近控制 | 判断 |
|---|---|---|---|
| memory-aware reward 的端到端增量 | MMLongBench-Doc **51.6→53.9**；LongDocURL **57.4→60.1** | Answer-GRPO | 最干净 family-level delta |
| 固定 evidence access 后仍有效 | EP-given final **45.4→48.0**；memory-only **41.2→43.5**；Pmmc **19.1%→16.4%** | gold pages + Answer-GRPO | 最强 materialization 归因 |
| 找到页仍会丢 state | 正确 EP-given 答案中 **42.5%** 的 terminal memory 无法单独作答 | gold pages | 证明 failure mode 存在 |
| 相对 static RAG 的更大增益 | **+8.1/+11.9** | RAG Top-3 | package-level，不能归因给 memory reward |

## What remains unproven

training compute 没有 matched：AWM-GRPO 每个 rollout 多两次短 Qwen3-14B text pass。memory-only answerability 依赖一个 frozen reader/judge，而且 unsupported 但刚好可作答的 claim 仍可能通过；实验也只覆盖一个 4B policy 与两个 long-document VQA benchmark。

## Field-map consequence

`retrieval → evidence materialization → retained state → downstream reasoning / stopping`。

这是 `early_signal`：应该把 evidence reached、evidence preserved、evidence grounded 分开测。但单篇 VQA training study 还不足以修改 durable Field Map。

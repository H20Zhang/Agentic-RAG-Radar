# The Retriever Should Remember: Experience-Amortized Reranking for Long-Term Agent Memory

*发表于 2026-08-24 · 检索与工具使用 · 重要性 3/5 · 已阅读全文 · 置信度：中*

[论文](https://arxiv.org/abs/2608.22767) · [代码](https://github.com/FengQi-HITSZ/earm)

> **TL;DR。** EARM 保留稀疏 query–memory relevance judgment，并补全其余 score matrix。LoCoMo top-10 accuracy 从 semantic 的 82.21% 升到 88.83%，full reranking 为 91.62%；direct scoring calls 减少 74.43%。固定 pool 消融支持 retained retrieval meta-state，但没有测试 memory 内容演化与完整生命周期成本。

| 30 秒判断 | |
|---|---|
| **为什么重要** | memory retriever 可以复用 relevance experience，而不必对每个 query 重新获取全部分数。 |
| **最强证据** | 在相同 observed anchors 上加入 completion，带来 **+0.78 至 +2.79 点**。 |
| **最大限制** | 单一固定 LoCoMo store 与顺序 query stream 可能提供了异常强的低秩复用结构。 |

## Problem

长期记忆应该只保留内容，还是也保留此前 query 与内容交互得到的检索判断？

## 研究增量

**Experience-amortized memory reranking**：过去的 query–memory score 成为持久状态，用于补全未来分数并减少重复 LLM scoring。

## Mechanism

**控制流。** `query → semantic top-200 → 打分 anchors → 更新 score matrix → low-rank completion → 选择 top-k`

直接打分预算按 query 序号递减，并不是 uncertainty/drift-adaptive；实验也没有在初始 semantic pool 之外扩展候选。

## Closest comparison

最近对照固定同一 memory pool 与 reranker，只切换 completion/experience components；跨系统总体分数不用于单独归因。

## Decisive evidence

| 主张 | 证据 | 最近控制 | 判断 |
|---|---|---|---|
| persistent score 改善 context | top-10 **82.21 → 88.83**，full 91.62 | 相同 store/pool/scorer | LoCoMo 上较强 |
| imputation 超过 anchors | **+0.78 至 +2.79pp** | 相同 anchors/budget | 关键组件证据 |
| 调用可摊销 | **307,982 → 78,736** | full reranking | call count 成立 |
| 扩展 candidate recall | 实验始终固定 pool | 无 | **未证明** |

最强 top-20 cell 的 temporal accuracy 没有提升；tokens、matrix compute、latency、ingestion、answer calls 与 dollars 均未报告。

## Field-map consequence

`retain content ↔ retain retrieval experience ↔ reacquire scores`

这是 State persistence 与 retrieval cost 的 early signal，不代表 matrix completion 普遍改善 memory。

## What remains unproven

让 memory 与用户流持续变化，独立控制 score retention、pool expansion、drift detection 与 direct-score budget，并完整报告 tokens、calls、latency、storage 与 matrix compute。

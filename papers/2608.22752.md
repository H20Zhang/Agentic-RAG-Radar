## Research question

When a long-running agent must shrink, partition, or retrieve its state, can it preserve safety-critical constraints without allocating the same fidelity to episodic logs and preferences?

## Research delta

The delta is **typed retention policy across three context-management operations**. Classification happens before compaction; constraints then use exact-preservation, scope replication, priority retrieval, and guard verification.

## Mechanism

**Control flow.** `classify item → compact/decompose/retrieve by type → verify constraints → accept or mark unsafe`

TypeRetrieve deserves careful reading. It does not merely rerank the same observations: it receives stored type/topic metadata and query-topic scope, pins applicable constraints, then fills residual slots by relevance.

## Where it fits

`retained state → semantic type → fidelity lane → verified materialization`

This adds a single-paper signal to State persistence: recoverability and reacquisition cost are not enough when some state has asymmetric loss cost.

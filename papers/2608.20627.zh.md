# 当失败继续传播：Agentic RAG 中的因果失败归因

*发表于 2026-08-20 · 评测与分析 · 重要性 4/5 · 已阅读全文 · 置信度 medium*

[论文](https://arxiv.org/abs/2608.20627) · [Artifact](https://github.com/anote-ai/Research-AgenticRAG)

> **TL;DR.** Certified hop fault 与 counterfactual rerun 表明：失败传播后，post-hoc answer coverage 会失去 exact-hop 信息；active probe 保留部分信号，但 denominator、compute 与 harness 都未匹配。

![Certified fault 的 frozen-hop 与 suffix-regeneration probe](../assets/visuals/2608.20627.webp)

**读图。** 已知 fault 被注入某一 hop；下方两支分别固定 corrupted evidence 继续执行，或重新生成 downstream suffix。两者都可能诊断成功或失败。**不要过读：** 实验只分析仍失败的 trajectory，且没有一种 intervention 普遍占优。

## Problem

Retrieval fault 改变后续搜索与推理之后，哪个 hop 仍能被识别为最终失败的原因？

## Mechanism

`run agent → inject certified fault → retain failed traces → freeze/regenerate suffix → compare outcome → attribute hop`

## Closest comparison

同一 failed trace 上比较 gold-answer coverage、cross-family LLM judge、frozen-hop repair 与 suffix regeneration；但 active probe 会重新运行 agent，成本并不匹配 post-hoc method。

## Decisive evidence

Structural fault 的 exact-hop coverage 为 0.91/0/0；judge 为 0.26/0.25/0.43；frozen 为 0.51/0.25/0.48。Content fault hop-2 上 suffix regeneration 仅 0.11，而 frozen 为 0.67。

## What remains unproven

跨 depth 的 survivor set 与 denominator 不同，不能当作普遍 depth trend。Corpus 保持干净，使 later retrieval 修复 54–85% interventions；headline 也仅来自一组 model×retriever×dataset×probe budget，且没有完整 token/call/latency/dollar table。

## Field-map consequence

这是 **propagation-conditioned failure attribution** 的 early signal，也是 Causal evaluation 的新坐标；单个 narrow matrix 不构成 durable map edit。

# Is Grep All You Need? How Agent Harnesses Reshape Agentic Search

**arXiv:** [2605.15184](https://arxiv.org/abs/2605.15184) · **Published:** 2026-05-14 · **Category:** Evaluation & Analysis · **Importance:** 4/5 · **AI confidence:** High

> **TL;DR.** The paper's strongest result is a confound: **retriever ranking is not invariant to the agent harness or the evidence-delivery path**. In some settings changing inline results to programmatic file reads reverses grep-versus-vector conclusions.

## Problem

Agentic search comparisons often talk as if the retriever is an isolated component. In reality, the surrounding harness controls prompts, tool schemas, result rendering, file access, and stopping behavior—all of which change how retrieval evidence is consumed.

## Core idea

Run a factorial comparison across lexical grep versus vector retrieval, four harnesses, multiple LLMs, and two result-delivery modes: inline tool output and programmatic file-based reading.

## Agent loop

`query → harness selects/schedules retrieval → evidence delivered inline or via file → model inspects → continue or answer`

## Retrieval design

The paper does not propose a new retriever; it treats retrieval mode × harness × delivery path as interacting experimental factors.

## Compared to what

This is an evaluation-design paper rather than a new retrieval method. The critical comparison is the same retrieval mode/model under different harness and delivery choices.

## Evidence

On the **116-question LongMemEval-S** subset, inline grep beats inline vector for every tested harness-model pair. But programmatic delivery flips the ordering on **five of ten** pairs. The sharpest example is GPT-5.4 in Codex: grep falls from **93.1% inline to 55.2% programmatic**, while programmatic vector reaches **67.2%**. The same Claude Opus 4.6 model also reaches 93.1% with Chronos grep versus 76.7% with Claude Code grep.

## Why it matters

This makes **harness × delivery path** a required causal axis for Agentic RAG evaluation. A retriever can look better or worse because the runtime changes how evidence enters the model, not because the underlying ranking quality changed.

## Limitations / questions

- Long-memory conversational QA contains many literal witnesses and may favor lexical search.
- Provider harnesses differ in multiple coupled behaviors, so the paper diagnoses the confound more cleanly than it isolates one causal mechanism.
- The decisive follow-up is a shared harness with swappable prompts/tool schemas/result renderers tested independently.

**Curator take:** **4/5.** Important because it invalidates a common evaluation assumption: “same model + different retriever” is not enough if the harness/evidence path changes around it.

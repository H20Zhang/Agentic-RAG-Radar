# The Retriever Should Remember: Experience-Amortized Reranking for Long-Term Agent Memory

*Published 24 Aug 2026 · Retrieval & Tool Use · Importance 3/5 · Full-text reviewed · Confidence medium*

[Paper](https://arxiv.org/abs/2608.22767) · [Code](https://github.com/FengQi-HITSZ/earm)

> **TL;DR.** EARM retains sparse query–memory relevance judgments and completes the remaining score matrix. On LoCoMo, top-10 accuracy rises from 82.21% semantic to 88.83%, versus 91.62% full reranking, while direct scoring calls fall 74.43%. The fixed-pool ablation supports retained retrieval meta-state; evolving memory contents and complete lifecycle cost are not tested.

| 30-second verdict | |

| **Why this paper matters** | A memory retriever can reuse relevance experience instead of reacquiring every score for every query. |

## Research question

Should long-term memory retain only content, or also the retrieval judgments learned while earlier queries interacted with that content?

## Research delta

The smallest delta is **experience-amortized memory reranking**: past query–memory scores become persistent state used to impute future scores, reducing repeated LLM scoring.

## Mechanism

**Control flow.** `query → semantic top-200 → score selected anchors → update causal score matrix → low-rank completion → choose top-k`

The direct-scoring budget shrinks by query index. It is not uncertainty- or drift-adaptive, and reported experiments never score outside the initial semantic pool.

## Evidence & attribution

| Claim | Evidence | Closest control | Assessment |
|---|---|---|---|
| Persistent scores improve context | Top-10 **82.21 → 88.83**, full rerank 91.62 | Same store/pool/scorer/answerer | Strong on LoCoMo |

| Candidate recall expands | All experiments use the same pool | None | **Not demonstrated** |

Temporal accuracy is unchanged in the strongest top-20 cell; open-domain gains are smaller. Tokens, matrix compute, latency, ingestion, answer calls, and dollars are absent.

## Where it fits

`retain content ↔ retain retrieval experience ↔ reacquire scores`

This is an early signal connecting State persistence with retrieval cost, not evidence that matrix completion universally improves memory.

## Open question

Stream evolving memories and heterogeneous users while independently varying score retention, pool expansion, drift detection, and direct-score budget. Report retrieval/answer quality plus all tokens, calls, latency, storage, and matrix compute.

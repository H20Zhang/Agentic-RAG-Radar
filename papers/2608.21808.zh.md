> **TL;DR.** Bounding-box reward 在作者 visual-RAG package 内提高 citation IoU 与 answer score；但所谓 process reward 只测 terminal crop，box overlap 也不能证明语义证据有效。

| 30 秒判断 | |
|---|---|
| **为什么重要** | 它把 visual evidence localization 变成显式训练目标与输出。 |
| **最强证据** | 7B full 为 **60.00/36.05** answer/citation；移除 citation rewards 后为 **54.20/20.56**。 |

## Problem

Multimodal RAG agent 能否不仅回答，还明确定位支持答案的 image region？

## Mechanism

`retrieve image → crop → inspect/repeat → answer + bbox → optimize answer/final-box/terminal-crop rewards`

## Closest comparison

最接近的归因来自 same-package reward ablation，而不是外部 leaderboard。所谓 process term 实际只用 terminal crop `c_T` 的 IoGT。

## Decisive evidence

Full vs no citation rewards 为 60.00/36.05 vs 54.20/20.56。移除 answer reward 后 citation 升至 41.65、answer 降至 53.20，说明两项目标可能冲突。

## What remains unproven

尚未证明 intermediate progression 得到监督，也没有证明 bbox overlap 等同 semantic support。Gold answer 与 gold coordinates 进入数据合成；teacher call、test-time tokens、crop calls、latency、dollars 与 stopping 都未闭合。

## Field-map consequence

这是 **visual evidence-localization rewards** 的 narrow early signal，不把 answer gain 泛化为 citation 的普遍因果效应。

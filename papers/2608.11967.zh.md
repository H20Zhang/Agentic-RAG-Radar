# LoongReflect：让 Long-Horizon Search State 可回滚

**中文** | [English](2608.11967.md) · [返回首页](../README.md) · [Research Library](../library/README.md)

[Paper](https://arxiv.org/abs/2608.11967) · **Importance: 4/5**

> **Research delta.** LoongReflect 把 search trajectory 从只能继续追加的 history，改成**可诊断、可回滚的 execution state**：发现 branch 被错误 evidence 污染后，回到 trusted prefix，保留 corrective lesson，再继续。

## Problem

Long-horizon search 中，一个早期 entity mismatch、错误 fact 或错误 hypothesis 可能污染后面很多轮 query。Terminal reward 很难把最后失败准确归因到最早的错误 decision。

普通 reflection 即使意识到“前面错了”，也可能只是继续在已经污染的 context 上追加文字，而不是恢复一个可信 execution state。

## Mechanism

`reason/retrieve → reflect → continue or backtrack → restore trusted prefix + corrective lesson → resume search → answer`

核心不是多一次 self-critique，而是**状态恢复语义**：把不可信 suffix 从 active trajectory 中移除，同时留下对后续有用的 correction。

## Closest comparison

论文比较 ReAct、Search-R1、AgenticRAG-R1 等，但最大的 attribution caveat 来自训练方式：teacher 拥有 privileged global trajectory view，用它生成 long-horizon reflection/backtracking supervision。

因此 headline gain 同时混合了：更强 supervision、reflection policy、rollback semantics。

## Decisive evidence

Qwen2.5-3B 上，论文报告七个 RAG benchmark 的 average F1：

- LoongReflect: **46.15**
- AgenticRAG-R1: **33.55**

这是明显的 package-level gain，但不能从这个数字单独推断“rollback 本身贡献了多少”。

## What remains unproven

最有判别力的 follow-up 是控制相同 teacher/supervision budget，分别比较：

`reflection only`、`reflection + explicit state restore`、`rollback without privileged global teacher`

并测 rollback frequency、wasted tool calls、latency/token cost 与 recovery success。

还要验证真实 environment 中 rollback 是否真的可执行：很多 tool action 是不可逆的，恢复 reasoning state 并不能恢复 external world state。

## Field-map consequence

它把 `persistent reasoning/search state` 再拆成：

`retained state × trust status × reversibility`

对 acting agent 来说，这个 distinction 比“有没有 memory”更具体。

# GTA-RAG：用图轨迹增强强化学习的多轮检索推理

> **TL;DR.** GTA-RAG 先把 graph path 变成 retriever-validated target trajectory，再进行 natural-QA RL。Matched ablation 支持 evidence-chain acquisition，但 headline package 同时改变 graph、retriever interface、synthetic data 与训练流程。

## Problem

Answer-only reward 是否能学会多轮搜索所需的完整 evidence chain，还是需要直接监督 target-document acquisition？

## Mechanism

`graph path → retriever validation → synthetic target trajectory → trajectory reward → natural-QA reward → inference search`

Inference 使用 PPR+dense union，因而 graph substrate 与 retrieval interface 都属于 package。

## Closest comparison

最干净的是同一 Qwen2.5-7B package 移除 trajectory-guided reward；外部 Search-R1、RouteRAG 等没有匹配 graph construction、interface、data 或预算。

## Decisive evidence

Full-chain coverage 为 74.1 vs 58.7，EM/F1 为 49.7/59.4 vs 46.2/56.0；graph-synthetic held-out set 上 complete-chain 为 74.1 vs 54.3。

## What remains unproven

尚未证明 policy 能迁移到自然且未见的 evidence chain；OpenIE graph、external generator、online tokens/latency、memory 与 dollar cost 都未闭合，repo 当前三阶段脚本也不完全对应论文两阶段 recipe。

## Field-map consequence

这是 **retriever-validated evidence-chain supervision** 的 package-level early signal，不把主表 gain 单独归因于 reward。

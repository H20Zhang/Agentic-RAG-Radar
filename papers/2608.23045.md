# From Inertia to Objectivity: Improving Deep Research Agents with Noise Isolation

*Published 24 Aug 2026 · Iterative Reasoning & Verification · Importance 4/5 · Full-text reviewed · Confidence medium*

[Paper](https://arxiv.org/abs/2608.23045)

> **TL;DR.** NIS-Agent isolates new search observations from the agent's self-authored trajectory, then validates cited inference steps before stopping. In IBIS, the same task/results presented in observer context improve re-search decisions by roughly 15–30 points across most models. End-to-end GAIA/WebWalkerQA gains and lower token use are promising, but the package changes filter, validation, and parts of the harness together.

## Research question

Does an agent become inertial because its own earlier search narration biases page triage, re-search, validation, and stopping?

## Research delta

The delta is **ownership-isolated search validation**. The worker judges current observations without its own trajectory; the manager later reorganizes the trace into cited local inferences and checks them separately.

## Mechanism

**Control flow.** `search → isolate task/query/results → browse or re-search → rebuild cited steps → validate locally → correct or stop`

This is a harness intervention as much as a policy intervention: it changes which state is visible at each decision and how evidence is delivered to the validator.

## Evidence & attribution

| Claim | Evidence | Closest control | Assessment |
|---|---|---|---|
| Ownership affects re-search decisions | Observer mode gains ~15–30 points | Same task and observations | Strong local causal evidence |
| Full package improves GAIA | GPT-4o **54.88 → 61.82** | Same backbone, reproduced smolagents DR | Package-level support |
| Both components help | no validation 56.96; Stage 1 58.79; Stage 2 61.82; no filter 59.39 | Nested ablation | Good, not full factorial |
| It uses fewer tokens | GPT-4o GAIA **219.8K → 147.3K** | Same end-to-end baseline | Supported overall |

The trained 8B result mixes SFT, GRPO, teacher-generated actions/rubrics, and the interface. Filtering can discard relevant pages; isolated validation can still ratify a flawed step.

## Where it fits

`observation → ownership framing → inspect/re-search → cited validation → stop`

This adds context ownership to the evaluation/harness decomposition. It remains a single-paper signal rather than a durable map node.

## Open question

Replay identical search traces under a full factorial over trajectory visibility, observation rendering, filter, validator stages, and stopping, with matched calls/tokens/latency. Measure both evidence recall and unsupported confident answers.

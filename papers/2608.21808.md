# MCite-RL: Towards Reliable Multimodal RAG via Citation-enhanced Agentic Reinforcement Learning

*Published 22 Aug 2026 · Learning & Optimization · Importance 3/5 · Full-text reviewed · Confidence medium*

[Paper](https://arxiv.org/abs/2608.21808)

> **TL;DR.** Bounding-box rewards improve citation IoU and answer score inside the authors' visual-RAG package. The advertised process reward is actually measured on the terminal crop, and box overlap does not prove semantic evidence use.

| 30-second verdict | |
|---|---|
| **Why this paper matters** | It makes visual evidence localization an explicit training and answer output. |
| **Strongest evidence** | Full 7B reaches **60.00/36.05** answer/citation versus **54.20/20.56** without citation rewards. |
| **Biggest caveat** | Only 8.6% of teacher trajectories survive filtering; runtime accounting and human validation of semantic support are absent. |

## Research question

Can an iterative visual RAG agent learn not only to answer, but to localize the image region supporting that answer?

## Research delta

MCite-RL adds final bounding-box IoU and terminal-crop IoGT terms to answer reward. The smallest defensible delta is **visual evidence-localization reward**, not per-step process supervision.

## Mechanism

`retrieve image → crop → inspect/repeat → answer + bbox citation → optimize answer/final-box/terminal-crop rewards`

## Evidence & attribution

| Claim | Evidence | Closest control | Assessment |
|---|---|---|---|
| Citation reward improves localization | 36.05 vs 20.56 citation | same package, no citation rewards | Supported |
| Citation reward improves answer score | 60.00 vs 54.20 | same ablation | Associated, single run |
| Reward supervises intermediate progress | IoGT uses only terminal crop `c_T` | method equation | **Not supported** |
| Objectives align automatically | no answer reward: citation 41.65, answer 53.20 | reward ablation | **Contradicted** |

No complete teacher tokens/cost, test-time tokens, retrieval/crop calls, latency, dollars, or stop distribution is reported. Gold answer and coordinates enter synthesis, and the strict filter selects an unusually easy subset.

## Where it fits

`visual retrieval trajectory → terminal localization supervision → answer with explicit evidence region`

This is an early signal for **visual evidence-localization rewards**, with a narrow evidence ceiling.

## Open question

Do stepwise, semantically validated localization rewards improve answer faithfulness under matched crop/search budgets, human support labels, multiple seeds, and a teacher pipeline whose selection bias and cost are fully reported?

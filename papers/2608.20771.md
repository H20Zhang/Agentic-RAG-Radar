> **TL;DR.** CAS adapts retrieval width from calibrated score mass and weights RL trajectories using answer NLL. Matched ablations improve average EM, but the formal guarantee is about marginal set coverage or miscoverage frequency—not end-to-end correctness.

## Research question

Can uncertainty calibrate both how many documents a search agent reads and which rollout trajectories influence policy learning?

## Research delta

Adaptive Prediction Sets select 1–5 documents by calibrated retrieval-score mass. Adaptive Conformal Inference updates an answer-NLL threshold and downweights high-NLL trajectories during GRPO. These mechanisms act at retrieval and learning time respectively.

## Mechanism

`query → adaptive evidence-set size → search/reason ≤4 rounds → answer NLL → adaptive trajectory weight → policy update`

At `alpha=.05`, retrieving 4.8 documents raises general QA but multi-hop falls to 0.234. Resource disclosure includes search and rollout caps plus hardware, but not total steps, GPU-hours, tokens, realized calls, latency, or dollars.

## Where it fits

`calibrated retrieval mass → query-conditioned evidence-set size`

This is an early signal for **conformal evidence-set sizing**, distinct from measured evidence-sufficiency routing.

## Open question

Does calibrated set sizing retain coverage under dataset shift and improve answer correctness under matched realized tokens/calls, while confidence is measured against evidence validity rather than answer likelihood alone?

# SkillAlchemy: Open-World Agent Skill Creation

*Published 24 Aug 2026 · Planning & Query Formulation · Importance 4/5 · Full-text reviewed · Confidence medium*

[Paper](https://arxiv.org/abs/2608.23417)

> **TL;DR.** SkillAlchemy turns an underspecified brief into contrastive acquisition targets, then admits findings only at evidence-supported scope. Across 87 tasks it scores **55.8%** versus **47.2%** for the strongest automated baseline; removing core stages costs 5.0–15.7 points. The package changes queries, evidence found, orchestration, schema, and artifact content, with incomplete creation-cost accounting.

## Research question

How can a creator discover requirements omitted by a brief without promoting one source's local practice into a universal reusable instruction?

## Research delta

OpenSkill already searches external sources. SkillAlchemy's narrower delta is:

`candidate factor → matched contrast/boundary/neighbor probe → focused acquisition → General/Scoped/Exclude admission`

## Mechanism

**Control flow.** `brief → operational frame → contrastive questions → structured findings → decision-aligned procedures → scope admission → skill package`

Source findings retain context and provenance. Conflicting treatment under matched conditions stays unresolved; insufficient support does not license generalization.

## Evidence & attribution

| Claim | Evidence | Closest control | Assessment |
|---|---|---|---|
| Package improves created skills | **55.8%** vs MUSE 47.2, OpenSkill 46.0, no-skill 35.9 | Automated skill creators | Strong package result |
| External search matters | Same creators gain **+6.9pp** with Web | Creator without Web | Supports source access, not SkillAlchemy policy |
| Core stages contribute | Each removal costs **5.0–15.7pp** | Same scope/budget | Best internal isolation |
| Admission resists bad sources | 0/4 promoted in each perturbation | Injected payload | Directional, very small n |

Creation reports 69.1K tokens per LLM call but not call count, pages, source tokens, search/tool calls, dollars, or stage costs. SkillAlchemy is best in three of four runtime configurations; Media is a clear weakness.

## Where it fits

`query formulation → evidence acquisition → persistent procedural materialization`

This is an early placement signal, not proof that the grammar or parallel multi-agent package causes the full gain.

## Open question

Give every creator identical retrieved documents, source-token mass, calls, and artifact length; then vary requirement probing and admission independently. Evaluate unsupported generalization, held-out transfer, execution success, and full creation/runtime cost.

# Structurally-bounded Agentic Graph Exploration for Evidence-Grounded Scholarly DeepSearch

*发表于 2026-08-25 · 检索与工具使用 · 重要性 5/5 · 已阅读全文 · 置信度：中*

[论文](https://arxiv.org/abs/2608.24809) · [代码](https://github.com/RadiantCrystal/CRASE)

> **TL;DR。** Crase 是对“deep search 必须 open-ended”的直接反例：外部搜索只负责 seeds，之后固定 1.5-hop citation neighborhood，用 claim-level support 剪边，再在 bounded graph 上排序。ICLR 上报告 **R@50 0.3659 vs 0.1220**，同时是 **5 vs 17–18 calls、235K vs 560–620K tokens、104 vs 249–272 s、$0.37 vs $1.76–$2.06**。但 output task、corpus substrate 与 model stack 也不同，不能把全部收益归给 boundedness。

| 30 秒判断 | |
|---|---|
| **为什么重要** | exploration extent 与 stopping 可以从 model policy 移到结构 substrate，并且这篇把 calls/tokens/time/dollars 一起报告。 |
| **最强证据** | ICLR 上 recall 和四类资源指标同时优于两个 proprietary deep-research baseline。 |
| **最大限制** | 对照的 output contract、模型与检索 substrate 并未完全匹配。 |

## Problem

open-ended deep research 让 candidate boundary、stopping、provenance 与资源消耗都依赖中间模型判断，难预测也难审计。

## Mechanism

`research plan → fixed seed searches → 1.5-hop citation expansion → atomic claims → entailment-weighted pruning → recency-aware PPR/SALSA → top-k`

seed 固定后，后续 candidate set 和 stopping 已知；LLM 只做局部 plan、claim extraction 和 edge judgment，不再决定全局 search loop 是否继续。

## Closest comparison

系统级最近对照是 DeepResearch-GPT / Claude；但它们与 Crase 的目标、模型和 substrate 不同。内部 PPR/SALSA、seed strategy、hop 分析更适合判断 Crase 自己哪些 design choice 有效。

## Decisive evidence

| 主张 | 证据 | 最近控制 | 判断 |
|---|---|---|---|
| 系统级效率 | **5 calls / 235K / 104s / $0.37** | DR-GPT 18/620K/272s/$1.76；DR-Claude 17/560K/249s/$2.06 | 成本口径很完整 |
| retrieval utility | ICLR **R@50 0.3659 vs 0.1220** | 两个 DR baseline | 强系统结果 |
| edge auditability | 50 edges 上 84% agreement，κ=0.71 | 3 experts | 有限但直接 |
| 设计敏感性 | ranking、seed、hop 改变 recall/MAP | internal variants | 支持结构选择重要 |

## What remains unproven

固定 scholarly corpus、seed retriever、generator、output contract 和 dollar/token budget，比较 fixed 1.5-hop、adaptive hop 与 open-ended tool search。这样才能回答 adaptivity 本身什么时候值得成本与方差。

## Field-map consequence

`query plan → bounded corpus interaction → explicit evidence graph → predetermined stop`

这是 `early_signal`：有结构的 domain 可以把 stopping/exploration bound 移出 policy。它还不足以改写一般性的 Field Map。

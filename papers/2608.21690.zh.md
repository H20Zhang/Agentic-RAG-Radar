## Problem

Agent 能否让完整历史始终可恢复，却不必把每个 event 都塞进 active prompt？

## Mechanism

`append event → retain lossless state → formulate Python query → aggregate/filter → print selected evidence → answer`

Ingestion 不用 LLM call；成本被推迟到 query program 与 environment execution。

## Closest comparison

BEAM10M 的 same-harness ablation 分别移除 persistent REPL、eviction index 或改用 lossy ingestion。LOCA 上同模型 CodeAct 则隔离更广义的 programmatic binding。

## Decisive evidence

Full 73.1 vs no REPL 65.8，no index 71.3，lossy ingestion 19.9。LOCA-256K 为 86.7 vs CodeAct 85.3，说明独属于 Scroll 的增量较小。

## What remains unproven

Cross-system memory comparison没有匹配 backbone、reader、retrieval budget 与 judge。较弱 backbone 在 LOCA-256K 崩溃；完整 latency、dollar、storage/index CPU 与 update lifecycle 也未报告。

## Field-map consequence

这是 **query-time programmatic context materialization** 的 early signal，连接 State persistence 与 Evidence materialization，但不足以修改 durable map。

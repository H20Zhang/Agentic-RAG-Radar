# EviGraph: Towards Verifiable Evidence Construction for Information-Seeking Agents

*发表于 2026-08-25 · 迭代推理与验证 · 重要性 5/5 · 已阅读全文 · 置信度：中*

[论文](https://arxiv.org/abs/2608.24667)

> **TL;DR。** EviGraph 把 Web 检索结果物化成 span-grounded claim–evidence graph，同时作为持久 working state 和 process reward surface。BrowseComp-Plus 上最干净的同架构比较是 **26.9% → 35.9%**；更大的 **2.7% → 26.9%** 同时改变 interface、verifier、搜索持续性和 stopping，不能归因给 graph memory 单项。

| 30 秒判断 | |
|---|---|
| **为什么重要** | evidence materialization 被做成显式状态后，retrieval、recording、contradiction 与 stopping failure 可以分开测。 |
| **最强证据** | 同一 dual-role architecture 与 interaction budget：**26.9% without RL → 35.9% with RL**。 |
| **最大限制** | frozen verifier 提供 privileged semantic judgment，且 page-token / latency / dollar accounting 不完整。 |

## Problem

线性搜索轨迹即使包含相关页面，也没有明确表达“哪个 source span 支持哪个 candidate 的哪个 constraint”，导致 grounding、冲突和 stopping 的 credit 混在一起。

## Mechanism

`question/constraints → graph-conditioned search → frozen page verifier → Add/Support proposal → structural commit → support/conflict/MISSING → continue or answer`

executor 不直接读取 raw pages；verifier 读取页面并给 source、verbatim span、tag 与 polarity；共享 policy 负责 graph-write proposal；deterministic validator 只检查 provenance 与结构 invariant，不做 semantic entailment 或 stopping 判断。

## Closest comparison

最关键的最近控制是同一个 dual-role architecture 的 no-RL 版本：它保留角色、接口和 interaction budget，只移除 process RL。monolithic Qwen3-8B 只能提供 package-level 边界。

## Decisive evidence

| 主张 | 证据 | 最近控制 | 判断 |
|---|---|---|---|
| process RL 的增量 | BrowseComp-Plus **26.9 → 35.9** | dual-role no-RL | 最强因果证据 |
| architecture package 很重要 | **2.7 → 26.9** | monolithic agent | 多因素同时变化 |
| 不是单纯多搜 | matched RL 比较中 search count 基本不变，generated tokens 更少 | same architecture | 支持 objective effect |
| 跨任务有效 | BrowseComp、GAIA、XBench 均报告增益 | transfer | 不能隔离机制 |

## What remains unproven

固定 raw search results、verifier outputs、answer model、stopping budget 和总 tokens/calls，再比较 verified linear log、typed table 与 claim graph，并独立切换 process reward。这样才能把 representation、privileged verifier 与 RL 分开。

## Field-map consequence

`retrieval → evidence materialization → persistent support/conflict state → continue / redirect / stop`

这是 `early_signal`，说明显式证据状态是值得独立比较的设计坐标；单篇工作还不足以把 graph representation 提升成稳定方向。

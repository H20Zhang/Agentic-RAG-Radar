# CAS：通过自适应检索与策略加权实现 Conformalized Agentic Search

*发表于 2026-08-21 · 学习与优化 · 重要性 3/5 · 已阅读全文 · 置信度 medium*

[论文](https://arxiv.org/abs/2608.20771) · [代码](https://github.com/S1llyBird/CAS)

> **TL;DR.** CAS 用 calibrated score mass 调整 retrieval width，再用 answer NLL 加权 RL trajectory。Matched ablation 提高 average EM，但理论保证只对应 set coverage / miscoverage frequency，不是 end-to-end correctness。

| 30 秒判断 | |
|---|---|
| **为什么重要** | 它把 top-k 从 global constant 变成 query-conditioned decision。 |
| **最强证据** | Qwen2.5-3B full **0.401**，no ACI **0.384**，fixed top-k=3 **0.389**。 |
| **最大限制** | Calibration 小且由 teacher 生成；NLL 不等于 factuality，没有 CI，Qwen3 thinking mode 还会停止搜索。 |

## Problem

不确定性能否同时控制 search agent 读多少文档，以及哪些 rollout 应影响 policy learning？

## Mechanism

`query → adaptive evidence-set size → search/reason ≤4 rounds → answer NLL → adaptive trajectory weight → update`

## Closest comparison

最干净的对照是同 package 移除 ACI，或把 APS 换成 fixed top-k=3。Search-R2 recipe 闭源，不能作为同等可执行控制。

## Decisive evidence

3B average 为 0.401 vs 0.384/0.389。8B 相对 Search-R2 总体只高 0.018，General QA 仅高 0.001。`alpha=.05` 虽取回更多文档，却使 Multi-Hop 降到 0.234。

## What remains unproven

239 个 teacher-created calibration queries 不能保证跨 dataset exchangeability；answer NLL 也不能证明 evidence validity。总 steps、GPU-hours、tokens、realized calls、latency 与 dollars 不完整。

## Field-map consequence

这是 **conformal evidence-set sizing** 的 early signal；它依据 calibrated rank mass，而不是已测量 evidence sufficiency，因此不与 D2 合并成趋势。

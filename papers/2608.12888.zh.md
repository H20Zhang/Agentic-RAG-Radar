# ReFind：Raw Archive 的 Retrieval Interface 也可以很“Agentic”

**中文** | [English](2608.12888.md) · [返回首页](../README.md) · [Research Library](../library/README.md)

[Paper](https://arxiv.org/abs/2608.12888) · **Importance: 4/5**

> **Research delta.** ReFind 把 intelligence 从 offline semantic preprocessing 移到 **question-time access interface + result-conditioned iteration**。它因此是检验“预先建 memory/index structure 是否必要”的强 raw-state control。

## Problem

如果 structured RAG/memory system 拥有 rich interface、multi-round control、session/time metadata，而 raw baseline 只有一次 BM25/top-k，那么结果很难说明 structure 本身有价值。

更合理的问题是：**保持 raw source 不变，只增强 access primitives 与 interaction loop，会回收多少所谓 structured-memory gain？**

## Mechanism

ReFind 在 raw timestamped chat turns 上暴露：

`keyword/time scope → BM25 search → local/session context inspection → save evidence → reformulate → skip seen sessions → repeat/stop → answer`

它提供 session-aware fusion、neighboring-turn expansion、temporal filtering 与 seen-session state。

## Closest comparison

两个 control 最有信息量：

- generic multi-round BM25：有 iteration，但缺 domain-native chat controls；
- one-search control：有更强 interface，但去掉 result-conditioned iteration。

这使 interface expressivity 与 multi-round adaptivity 可以被部分分开。

## Decisive evidence

LongMemEval-S/M：

- ReFind: **93.2 / 89.3**
- generic-agentic BM25: **78.7 / 82.2**
- one-search: **84.7 / 68.9**

跨六个任务 aggregate mean 为 **58.2**，高于论文比较的 HippoRAG 2 **53.2** 与 BM25-RAG **48.8**。但 EventQA 略偏向 single-shot BM25，说明“更多 interaction”并非普遍必要。

## What remains unproven

ReFind 并没有证明 precomputation/semantic structure 总是多余。它证明的是 baseline 必须更强。下一步应把 raw iterative search 与 structured/graph retrieval 放到同一：

`model × source snapshot × online token × latency × retrieval rounds × offline construction/update cost`

下比较。

此外，chat refinding 和 open-domain synthesis / acting-agent search 的 workload 不同，raw lexical interface 的边界需要跨 domain 验证。

## Field-map consequence

RAG 的 comparison axis 不应只有 `retriever type`，至少还要拆开：

`source representation × access interface × result-conditioned control × retained interaction state`

否则所谓“agentic policy gain”很容易其实来自 interface gain。

# AWM: Answerable Working Memory for Long-Document VQA Agents

*Published 26 Aug 2026 · Learning & Optimization · Importance 4/5 · Full-text reviewed · Confidence medium*

[Paper](https://arxiv.org/abs/2608.25618) · [Code](https://github.com/DongzhuoranZhou/AWM)

> **TL;DR.** AWM shows that reaching the right page does not guarantee that an agent preserves usable evidence in terminal working memory. With the same Qwen3-VL-4B agent family, Answer-GRPO → AWM-GRPO improves final accuracy **51.6→53.9** on MMLongBench-Doc and **57.4→60.1** on LongDocURL; under gold evidence pages, final/memory-only accuracy improves **45.4/41.2→48.0/43.5** while memory-missing-correct falls **19.1%→16.4%**. The clean claim is about evidence materialization, not a new retrieval backend.

## Research question

After a retrieval agent reaches relevant pages, can the state it writes still be an independent bottleneck because question-relevant evidence was not preserved in terminal working memory?

## Research delta

The useful decomposition is:

`page acquisition → evidence extraction/materialization → retained working state → final answering`.

AWM turns the middle transition into an explicit training and evaluation surface. After a run, page images and trajectory context are removed; a frozen reader receives only the question and terminal memory and tests whether that artifact can still support the answer.

## Mechanism

A Qwen3-VL-4B policy repeatedly retrieves top-3 page images through a fixed Jina-v4/Qdrant interface, inspects them, and must append a source-linked finding before continuing. During GRPO training, a frozen Qwen3-14B reader answers from `(question, terminal memory)` and a frozen scorer evaluates the memory-only answer together with the final answer. The reward therefore prefers answer-correct trajectories whose saved state remains answerable. Deployment keeps the same agent/tool loop and adds no reader/scorer call.

## Evidence & attribution

| Claim | Evidence | Closest control | Assessment |
|---|---|---|---|
| Memory-aware reward improves the same agent family | **51.6→53.9** MMLongBench-Doc; **57.4→60.1** LongDocURL | Answer-only GRPO | Cleanest end-to-end delta |
| Gain survives fixed evidence access | EP-given: final **45.4→48.0**, memory-only **41.2→43.5**, Pmmc **19.1%→16.4%** | Gold evidence pages + answer-only GRPO | Strongest materialization attribution |
| Successful page access can still leave poor state | Among correct EP-given answers, **42.5%** have unanswerable terminal memory | Gold evidence pages | Establishes the failure mode |
| Full package beats static RAG by more | **+8.1/+11.9** over RAG Top-3 | RAG Top-3 | Package-level only; not attributable to memory reward |

Training compute is not matched: AWM-GRPO adds two short Qwen3-14B text passes per rollout relative to answer-only GRPO. The answerability metric also depends on one frozen reader/judge and can accept an unsupported but answerable memory claim.

## Where it fits

`retrieval → evidence materialization → retained state → downstream reasoning / stopping`.

This is an `early_signal` for treating post-retrieval state quality as its own coordinate. It does not establish that answerable working memory is a durable field-level direction or that this reward is generally superior across agents.

## Open question

Hold the complete retrieval trajectory, answer model, and training compute fixed; compare memory-writing objectives while independently scoring (1) memory-only answerability, (2) claim-level source support, and (3) whether later retrieval/stopping decisions improve when they consume that state.

> **TL;DR.** 最稳固的结果是 fresh evidence allocation：在 context size 与轮数匹配时，rotation 明显优于固定复用。完整 feedback scheduler 与 deep rotation 统计上打平，论文没有报告二者的 matched cost 差异。另一个等 evidence slots 的比较中，顺序执行的 `(2,12)` 优于 one-shot `(24,1)`，但 latency 为 17.5s 对 1.7s；这说明的是 compute/interface package 的前沿，不能归因于 timing 本身。

## Problem

固定 context budget 下，质量究竟来自更大上下文、跨轮 fresh evidence，还是 feedback-conditioned selection？

## Mechanism

`retrieve → estimate marginal value → allocate bounded context → generate feedback → schedule next portfolio → answer`

Leave-one-out 阶段每轮还需 `k+1` 次 teacher-forced passes，这不是可忽略的实现成本。

## Closest comparison

最接近的因果对照是在相同 context size 与 round count 下比较 fixed reuse、fresh rotation 与 feedback allocation。等 evidence slots 的 `(2,12)` 对 `(24,1)` 同时改变 generation count、interface 与 test-time compute，因此不是隔离 allocation timing 的实验。

## Decisive evidence

| 主张 | 证据 | 判断 |
|---|---|---|
| Fresh evidence 有效 | 0.397 vs 0.257 | 强 |
| 重复分配 package 优于等 slots 的 one-shot | +0.144，但 generation count/interface/compute 不同 | 支持 package 级结论，不能只归因于 timing |
| Feedback scheduler 带来终局增益 | 0.309 vs 0.303，`q=0.343` | **未建立** |
| Scheduler-only 有效 | 0.300 vs 0.303，`q=0.717` | **不支持** |

## What remains unproven

尚未证明复杂 scheduler 能在 matched evidence、calls、tokens、latency 与 decoding 下胜过优化后的 rotation；论文也未报告 full ASCP 与 deep rotation 的 matched cost 差异。顺序 `(2,12)` 相对 one-shot `(24,1)` 约 10× latency，限制的是 package 级部署主张。

## Field-map consequence

这是 **fresh-evidence context allocation** 的 early signal，强化 Adaptivity placement 与 Resource accounting 的实验坐标，但单篇不修改 durable map。

## Visual QC failure observed

Two attempted GPT-image generations for the READ visual produced generic **repository dashboard mockups** and invented unsupported UI facts/counts instead of the requested single-paper conceptual explainer. They were **discarded and not committed**.

The maintenance task was tightened so future visual generation must:

- generate exactly one named paper per invocation;
- reject dashboards/multi-paper collages while paper backfill remains;
- reject invented paper counts, dates, arXiv IDs, benchmark results, or taxonomy statistics;
- keep the record `pending` / `needs_regeneration` when visual QC fails.

## Compaction/editorial changes

The multi-role protocol now explicitly separates **Discovery → Inclusion Judge → Research Reader → Visual Explainer → Evidence Auditor/Skeptical Reviewer → Research Editor**. Weekly/monthly synthesis adds independent Clusterer/Field Mapper and Trend Skeptic roles.

The main causal lens is now explicit:

`substrate × operation set × state × policy × budget × base model`

The purpose is to avoid attributing system-level gains to “agentic control” when retrieval primitives or budgets changed at the same time.
